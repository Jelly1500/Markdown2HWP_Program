# 버그 리포트

## 어떤 버그인가요?

> 동일한 마크다운 문서를 서로 다른 템플릿으로 변환할 때, '템플릿문서1.hml'에서만 이모지가 '□' 문자로 깨져서 출력되는 현상이 발생합니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 특수 문자 테스트 문서
3. 사용했던 템플릿: 
   - template_ex_01.hml ~ template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml (문제 발생)

테스트한 이모지 포함 텍스트:
```text
이모지와 혼합: 안녕하세요👋 Hello🌏 こんにちは🎌
```

<br><br>

## 어떤 과정에서 버그가 발생하였나요?

1. 특수 문자 테스트용 마크다운 문서 작성
2. 각각의 템플릿으로 변환 테스트 수행
3. 결과 비교 시 발견한 차이점:
   - 대부분의 템플릿: 이모지가 정상적으로 표시됨
   - 템플릿문서1.hml: 이모지가 '□' 문자로 깨져서 출력됨

### 예상되는 원인:
1. 템플릿문서1.hml의 문자 인코딩 설정이 다를 수 있음
2. 해당 템플릿의 글꼴이 이모지를 지원하지 않을 수 있음
3. HWPML 변환 과정에서 특정 템플릿에 대한 유니코드 처리가 다를 수 있음
