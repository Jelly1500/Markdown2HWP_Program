# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에 **복잡한 링크 구조**가 포함되어 있을 때, **링크의 title 속성, 앵커 링크, 인라인 CSS 스타일**과 **HTML 인라인 요소들**(`<u>`, `<small>`, `<code>`, `<mark>`, `<del>` 등)이 **완전히 무시**되어 변환되지 않는 심각한 문제입니다. **웹사이트 메뉴 구조도, 사이트맵, 네비게이션 설계안** 등을 문서화할 때 사용되는 **상세한 링크 정보와 사용자 경험 요소**가 **통째로 사라져** 문서의 **핵심 네비게이션 설계 정보가 완전히 소실**됩니다. 이는 **공공기관의 웹사이트 개편, 포털 사이트 구축, 정보 아키텍처 설계** 등에서 **메뉴 구조와 링크 체계**를 문서화할 때 필수적으로 사용되는 구조로, 이러한 **전문 문서의 가장 중요한 네비게이션 정보가 변환되지 않아** 문서 자체가 **무의미**해지는 치명적 결함입니다.

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 시도
3. 변환 결과 확인:
   - **모든 템플릿에서 동일한 심각한 오류 발생:**
     * **모든 링크의 title 속성이 완전히 무시됨**
     * **HTML 인라인 요소들이 모두 사라짐**
     * **앵커 링크와 내부 네비게이션 구조 정보 소실**
     * **복잡한 메뉴 구조의 핵심 설계 정보 대폭 축소**

### 구체적인 문제 상황:
1. **기대되는 결과:**
   - **링크 title 속성**: "주거 안정 관련 정책 및 서비스 안내", "청년 대상 주거 지원 상세" 등의 상세 설명이 툴팁이나 별도 표시로 제공
   - **HTML 인라인 요소**: 
     * `<u>온라인 상담 가능</u>` → 밑줄 강조
     * `<small>(자녀 수별 혜택 상이)</small>` → 작은 글씨 부가 설명
     * `<code style="color:blue;">(필수 서류 확인)</code>` → 파란색 코드 스타일
     * `<mark>(2025년 개정)</mark>` → 하이라이트 표시
     * `<del>(결과는 참고용입니다)</del>` → 취소선 표시
   - **앵커 링크**: `#housing-youth`, `id="housing-youth"` 등의 내부 링크 연결 관계
   - **각 메뉴와 링크가 시각적으로 구분**되어 **완전한 사이트맵** 형태로 표시

2. **실제 발생하는 결과:**
   ```
   # 2025년 개편 예정인 '국민행복포털' 메뉴 구조도(안)

   ## 1. 생활 지원 서비스

   - 주거 안정 지원
     1. 청년 주거 지원 프로그램
        - 청년 월세 특별지원
        - 주택 구입 및 전세자금 대출 안내
     2. 신혼부부 및 출산 가구 지원
        - 특별공급 알리미
        - 육아기 주거안정 지원
   - 일자리 및 창업 지원
     - 구직 정보 검색
     - 창업 지원 프로그램 안내
   ```
   - **모든 링크의 상세 설명(title 속성)이 완전히 사라짐**
   - **인라인 HTML 요소들의 시각적 효과 전무**
   - **앵커 링크와 내부 연결 구조 정보 소실**
   - **메뉴 구조도의 핵심 네비게이션 정보 대폭 축소**

### 완전히 무시되는 복잡한 링크 구조:
1. **링크 title 속성**
   ```markdown
   [주거 안정 지원](/services/housing "주거 안정 관련 정책 및 서비스 안내")

   [국가 건강검진 안내](/services/health/checkup "국가 건강검진 대상자 조회 및 예약")
   ```

2. **앵커 링크와 ID 속성**
   ```markdown
   [청년 주거 지원 프로그램](#housing-youth)
   <a id="housing-youth"></a>청년 주거 지원 상세 안내 페이지
   ```

3. **HTML 인라인 요소들**
   ```markdown
   [주택 구입 및 전세자금 대출 안내 (<u>온라인 상담 가능</u>)]
   [육아기 주거안정 지원 <small>(자녀 수별 혜택 상이)</small>]
   [온라인 신청 절차 <code style="color:blue;">(필수 서류 확인)</code>]
   [검진 주기 및 항목 상세 <mark>(2025년 개정)</mark>]
   [온라인 자가진단 <del>(결과는 참고용입니다)</del>]
   ```

4. **복잡한 중첩 링크 구조**
   ```markdown
   - 일자리 및 창업 지원
     - 창업 지원 프로그램 안내
       1. 청년 창업사관학교 입교 안내
       2. 스타트업 정책자금 융자
          - 온라인 신청 절차
   ```

5. **외부 링크와 인용구 조합**
   ```markdown
   > 예시: [국립중앙박물관 특별전 예약], [국립현대미술관 관람 예약] 등
   ```

### 특히 문제가 되는 상황:
1. **공공기관 웹사이트 개편 프로젝트**
   - **시민 서비스 포털, 정부통합전산센터** 등의 **메뉴 구조 설계안 작성**
   - **정보 아키텍처 설계**와 **사용자 경험(UX) 플로우** 문서화
   - **링크 설명 정보 소실**로 **메뉴 기능과 목적 파악 불가** 및 **사용자 경험 설계 제약**

2. **포털 사이트 구축 및 리뉴얼**
   - **국민신문고, 정부24, 나라장터** 등의 **사이트맵과 네비게이션 체계**
   - **접근성 요구사항**과 **사용자 편의성** 검토를 위한 **상세 링크 정보**
   - **링크 title 속성 부재**로 **접근성 검토 불가** 및 **스크린 리더 지원 평가 제약**

3. **시스템 기획서 및 제안 요청서(RFP)**
   - **정보시스템 구축 사업**의 **메뉴 구조 요구사항 명세**
   - **입찰 업체의 이해도 평가**와 **기능 구현 범위** 확인
   - **상세 네비게이션 정보 부재**로 **요구사항 이해 오류** 및 **개발 범위 모호성**

4. **웹 접근성 및 사용성 평가 문서**
   - **웹 접근성 준수 현황**과 **개선 방안** 문서화
   - **링크 텍스트와 설명의 적절성** 평가
   - **인라인 요소 정보 소실**로 **접근성 평가 기준 적용 불가** 및 **개선 방향 설정 제약**

### 예상되는 원인:
1. **링크 title 속성 파싱 부재**
   - 마크다운 링크에서 **title 속성을 인식하지 못함**
   - **`[텍스트](URL "title")` 문법** 지원 부족
   - **한글 문서의 링크 요소**에서 **title 정보 표현 방법 없음**

2. **HTML 인라인 요소 지원 한계**
   - **`<u>`, `<small>`, `<mark>`, `<del>` 등 인라인 태그** 완전 무시
   - **인라인 CSS 스타일** (`style="color:blue;"`) 처리 부재
   - **한글 문서의 텍스트 서식**으로 **대체 표현 기능 없음**

3. **앵커 링크 및 ID 속성 미지원**
   - **내부 링크 구조** (`#anchor`) 인식 부재
   - **HTML id 속성** 처리 기능 없음
   - **문서 내 네비게이션 구조** 표현 방법 부족

4. **복잡한 마크다운 확장 문법 한계**
   - **GitHub Flavored Markdown** 등의 **확장 문법** 미지원
   - **마크다운과 HTML 혼용 구조** 파싱 한계
   - **현대적인 웹 문서 작성 표준**과 **한글 문서 표준** 간 **변환 체계 부재**

   ```markdown
   | 청년 주거 지원 프로그램 | #housing-youth | 청년 대상 주거 지원 상세 |
   ```
   - **링크 정보는 보존**되지만 **구조적 연관성 약화** 및 **가독성 저하**

2. **인라인 요소를 마크다운 문법으로 대체**
   ```markdown
   [주택 구입 및 전세자금 대출 안내 (**온라인 상담 가능**)]
   [육아기 주거안정 지원 _(자녀 수별 혜택 상이)_]
   [검진 주기 및 항목 상세 **2025년 개정**]
   ```
   - **기본 강조**는 가능하지만 **세밀한 시각적 구분 효과 상실**

3. **앵커 링크를 섹션 번호로 대체**
   ```markdown
   [청년 주거 지원 프로그램](#1-1-1)

   #### 1.1.1 청년 주거 지원 상세 안내
   ```
   - **내부 링크 기능**은 일부 구현되지만 **직관적 앵커명 상실**

4. **주석과 각주 활용**
   ```markdown
   [주거 안정 지원][1]

   [1]: /services/housing "주거 안정 관련 정책 및 서비스 안내"
   ```
   - **title 정보는 보존**되지만 **문서 구조 복잡성 증가**

### 근본적 해결 방안 제안:
1. **마크다운 링크 완전 지원**
   - **title 속성 포함 링크 문법** 완전 파싱
   - **앵커 링크와 ID 속성** 지원
   - **한글 문서의 하이퍼링크**에 **상세 정보 매핑**

2. **HTML 인라인 요소 완전 매핑**
   - **모든 인라인 HTML 태그**를 **한글 문서 서식으로 변환**
   - **인라인 CSS 스타일**을 **한글 문서 글자 서식으로 매핑**
   - **시각적 구분 효과** 최대한 보존

3. **웹 네비게이션 전용 변환 모드**
   - **메뉴 구조도, 사이트맵** 등을 **자동 감지**
   - **링크 중심 문서**에 **특화된 변환 옵션**
   - **계층적 링크 구조**를 **최적화된 형태**로 변환

4. **하이브리드 웹-문서 링크 표준**
   - **웹 표준 링크 구조**와 **한글 문서 하이퍼링크**를 **완벽하게 연결**
   - **접근성 정보**와 **사용자 경험 요소** 모두 보존
   - **현대적인 웹 정보 아키텍처 설계**에 **완전 대응**
