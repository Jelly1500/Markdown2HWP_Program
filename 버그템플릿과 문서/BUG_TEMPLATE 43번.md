# 버그 리포트

## 어떤 버그인가요?

> **국가 디지털 전환 및 AI 윤리 규범 수립 연구**와 같은 **극단적으로 긴 제목**이 포함된 문서에서 **특정 템플릿에서만 텍스트 겹침 및 줄바꿈 처리가 실패**하는 버그입니다. **template_ex_01, 02, 03**에서는 **텍스트가 모두 겹쳐서 한 줄에 모두 표시하려는 문제**가 발생하지만, **새템플릿, 템플릿문서, 템플릿문서1**에서는 **정상적으로 줄바꿈 처리**되어 **템플릿별 일관성 부족**이 심각한 문제입니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. **실행 환경**: Windows 10, Python 가상환경  
2. **테스트 문서**: 2025년도 국가 디지털 전환 촉진 및 인공지능(AI) 윤리 규범 확립을 위한 포괄적 다부처 연계 중장기 전략 수립 연구 (최종보고서 요약)  
3. **테스트한 템플릿 (템플릿별 차이 발생)**:  
   - template_ex_01.hml ❌ **텍스트 겹침, 한 줄 표시 시도**  
   - template_ex_02.hml ❌ **텍스트 겹침, 한 줄 표시 시도**  
   - template_ex_03.hml ❌ **텍스트 겹침, 한 줄 표시 시도**  
   - 새템플릿.hml ✅ **정상 줄바꿈 처리**  
   - 템플릿문서.hml ✅ **정상 줄바꿈 처리**  
   - 템플릿문서1.hml ✅ **정상 줄바꿈 처리**

## 원래는 어떻게 되어야 하나요?

### ✅ **기대되는 정상 동작**
1. **모든 템플릿 일관성**: 동일한 문서가 모든 템플릿에서 동일한 품질로 출력
2. **자동 줄바꿈**: 긴 제목의 적절한 위치에서 자동 줄바꿈
3. **반응형 폰트**: 제목 길이에 따른 자동 폰트 크기 조정
4. **읽기 편의성**: 텍스트 겹침 없이 모든 내용이 명확하게 표시

### 🎯 **템플릿 통일 필요성**
- **문서 유형별 제약 없음**: 긴 제목 문서도 모든 템플릿 선택 가능
- **기관별 표준 준수**: 특정 기관의 표준 템플릿 사용 보장
- **품질 예측 가능성**: 템플릿 선택과 관계없이 일관된 품질

```markdown
## 제1장 서론: 본 연구의 추진 배경, 국내외 디지털 전환 현황 심층 분석, 인공지능 기술 발전의 명암과 윤리적 과제 그리고 본 보고서의 목적과 범위에 대한 포괄적 기술

대한민국의 미래 경쟁력 확보와 국민 삶의 질 향상을 위한 핵심 동력으로서 디지털 전환의 중요성은 날로 증대되고 있으며, 특히 인공지능(AI) 기술은 산업, 경제, 사회 전반에 걸쳐 혁명적인 변화를 가져올 잠재력을 지니고 있습니다. 그러나 이러한 기술의 급격한 발전은 데이터 편향성, 알고리즘의 불투명성, 일자리 대체 우려, 그리고 예기치 못한 사회적 위험과 같은 다양한 윤리적, 사회적, 법적 과제를 동반하고 있습니다.
```

### 🔧 **근본 원인 분석**
1. **템플릿별 CSS 스타일링 차이**
   - 일부 템플릿: `word-wrap: break-word` 미적용
   - 일부 템플릿: `white-space: nowrap` 강제 설정

2. **페이지 레이아웃 제약**
   - 고정 너비 설정 vs 유동적 너비 설정
   - 마진 및 패딩 처리 방식 차이

3. **폰트 크기 대응 방식**
   - 자동 크기 조정 vs 고정 크기 유지
   - 긴 텍스트에 대한 우선순위 설정 차이

### 🏢 **공공기관 업무 영향도**
1. **실제 발생 가능한 문서 유형**
   - 정책 연구 보고서: 국책연구기관의 장기 연구 보고서
   - 법령 및 규정 문서: 복잡한 법령 제정안 제목
   - 국정과제 및 계획서: 국정운영계획의 세부 과제명

2. **업무상 제약 사항**
   - **문서 품질 저하**: 읽을 수 없는 제목으로 인한 내용 파악 어려움
   - **템플릿 선택 제약**: 긴 제목이 포함된 문서는 특정 템플릿으로만 제한
   - **배포 및 공유 문제**: 수신자별로 다른 템플릿 결과물 제공 필요

### 💡 **즉시 해결 방안**
1. **CSS 스타일 통일화**
   ```css
   h1, h2, h3 {
       word-wrap: break-word;
       word-break: keep-all;
       line-height: 1.4;
       margin: 1em 0;
   }
   ```

2. **반응형 폰트 크기 적용**
   - 제목 길이에 따른 자동 폰트 크기 조정
   - 최소/최대 크기 제한 설정

3. **템플릿별 일관성 확보**
   - 모든 템플릿에 동일한 텍스트 처리 로직 적용
   - 긴 텍스트 처리 가이드라인 수립

### 📝 **사용자 의견**
> **"이렇게 극단적으로 긴 제목일 경우 새템플릿.hml, 템플릿문서.hml, 템플릿문서1.hml 에서는 문제가 없으나 template_ex_01.hml, template_ex_02.hml, template_ex_03.hml에서는 텍스트가 모두 겹처서, 한줄에 모두 표시하려는 문제가 있음"**

이는 **공공기관의 공식 문서 작성**에서 **템플릿 의존성**으로 인한 **심각한 제약을 가하는 이슈**로, **모든 템플릿에서 일관된 긴 텍스트 처리**가 보장되어야 합니다.
