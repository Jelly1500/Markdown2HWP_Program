# 버그 리포트

## 어떤 버그인가요?

> 특정 템플릿(template_ex_01~03.hml)에서 마크다운의 제목(##)과 인용구("")가 한글 문서로 변환될 때 동일한 서식으로 처리되는 현상이 발생합니다. 이는 문서의 구조적 가독성을 해치고 내용의 위계질서를 모호하게 만듭니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 영국의 유명 인사 탐구
3. 문제가 발생하는 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml

4. 정상 작동하는 템플릿:
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
## 셜록 홈즈 (Sherlock Holmes)
셜록 홈즈는 아서 코난 도일 경이 창조한 **가상의 탐정**입니다.
그의 *날카로운 관찰력*과 추리 능력은 전 세계적으로 유명합니다.

---
**셜록 홈즈의 주요 특징**
- 「관찰과 추리」: 사소한 단서를 통해 사건의 본질을 꿰뚫어 보는 능력
- 「법의학적 접근」: 활동 당시 시대를 앞서간 과학적 수사 기법 활용
- 「베이커 가 특공대」: 거리의 아이들을 정보원으로 활용하는 독특한 네트워크

"불가능한 것을 모두 제거하고 나면, 남는 것이 아무리 믿을 수 없는 것일지라도 그것이 진실이다."
```

<br><br>

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - template_ex_01~03.hml에서 발생하는 문제:
     * 제목 `## 셜록 홈즈 (Sherlock Holmes)`와 인용구 `"불가능한 것을..."`이 동일한 서식으로 변환됨
     * 제목의 계층 구조가 시각적으로 구분되지 않음
     * 인용구의 특수성이 드러나지 않음
   - 새템플릿.hml, 템플릿문서.hml, 템플릿문서1.hml에서는 정상적으로 구분되어 변환됨

### 예상되는 원인:
1. template_ex_01~03.hml의 스타일 정의에서 제목과 인용구의 구분이 누락됨
2. 해당 템플릿들의 HWPML 구조에서 제목과 인용구에 대한 서식 매핑이 동일하게 설정됨
3. 마크다운 변환 시 특정 템플릿에서 요소 구분이 제대로 이루어지지 않음
4. 구 버전 템플릿의 스타일 정의가 현대적인 마크다운 요소를 제대로 지원하지 않음
