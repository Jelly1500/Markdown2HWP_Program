# 버그 리포트

## 어떤 버그인가요?

> template_ex_01.hml 템플릿에서 들여쓰기된 목록의 불릿 기호(-)가 빈칸 상자(□)로 변환되는 현상이 발생합니다. 이는 문서의 가독성을 해치고 일반적인 목록 표시 관례와 맞지 않습니다. 단, 이것이 개발 시 의도한 것인지는 확인해볼 필요가 있습니다. ▢리스트 와 같이 문서에 되어있는데, 이것이 원인인 듯 합니다. 

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 발 씻기 방법 안내
3. 문제가 발생하는 템플릿: 
   - template_ex_01.hml

4. 정상 작동하는 템플릿:
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
1. **발 적시기**
    - 따뜻한 물에 발을 충분히 적십니다.
2. **비누칠하기**
    - 발바닥, 발등, 발가락 사이를 부드럽게 문질러 거품을 냅니다.
3. **발가락 사이 문지르기**
    - 각 발가락 사이를 손가락으로 벌려가며 꼼꼼히 문질러 세척합니다.
4. **발뒤꿈치와 발옆 문지르기**
    - 발뒤꿈치와 발 옆부분을 손바닥으로 원을 그리며 문질러 줍니다.
5. **충분히 헹구기**
    - 비누 거품이 남지 않도록 흐르는 물에 발을 깨끗이 헹굽니다.
6. **물기 제거**
    - 수건이나 종이타월로 발가락 사이까지 말끔히 물기를 닦아 냅니다.
7. **마무리**
    - 로션이나 크림을 바르고, 깨끗한 양말을 신어 발을 보호합니다.
```

<br><br>

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - template_ex_01.hml에서 발생하는 문제:
     * 들여쓰기된 목록의 불릿(-)이 빈칸 상자(□)로 변환됨
     * 일반적인 목록 표시 방식과 달라 가독성이 떨어짐
     * 문서의 전문성과 심미성이 저하됨
   - 다른 템플릿에서는 정상적인 불릿 또는 대시로 변환됨

### 예상되는 원인:
1. template_ex_01.hml의 HWPML 구조에서 들여쓰기된 목록의 불릿 스타일이 잘못 정의됨
2. 마크다운의 들여쓰기된 목록 변환 시 특수 문자 매핑이 부적절하게 설정됨
3. 템플릿의 기본 불릿 스타일이 빈칸 상자로 하드코딩되어 있을 가능성
4. 들여쓰기 수준에 따른 불릿 스타일 차별화 로직이 누락됨
