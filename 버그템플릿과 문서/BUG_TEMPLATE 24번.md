# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에서 **특수문자(!,@,*,?,#,//,+,&,<,^,%,(,=,` 등)로 시작하는 목록 항목**이 포함되어 있을 때, "**알 수 없는 오류**"가 발생하며 한글 문서 변환이 **완전히 실패**하는 치명적인 문제가 발생합니다. 이는 IT 관련 문서, 시스템 점검 보고서, 기술 매뉴얼 등에서 빈번하게 사용되는 특수문자 표기법이 변환 엔진과 충돌을 일으켜 문서 전체를 사용할 수 없게 만드는 심각한 오류입니다. 프로그램이 중단되거나 빈 파일이 생성되어 업무에 큰 지장을 초래합니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 2025년 상반기 정보 시스템 정기점검 결과 및 조치 계획
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
# 2025년 상반기 정보 시스템 정기점검 결과 및 조치 계획

## 1. 서버 장비 점검 결과

-   **웹 서버 (WEB-01, WEB-02)**
    1.  ! CPU 사용률 평균 85%로 임계치 근접 (WEB-01).
        -   @ 조치 계획: 트래픽 분산 및 자원 증설 검토.
    2.  * 보안 패치 최신 상태 유지 중 (WEB-02).
-   **데이터베이스 서버 (DB-01)**
    -   ? 백업 주기 및 복구 테스트 결과 확인 필요.
        1.  # 현재 백업 주기: 매일 03:00.
        2.  // 최종 복구 테스트 일자: 2024년 12월 15일.
    -   + 스토리지 잔여 용량 20% 미만, 증설 고려.

## 2. 네트워크 장비 점검 결과

-   **라우터 (R-MAIN)**
    -   & 펌웨어 버전 업데이트 권장 (제조사 공지 확인).
    -   < 연결 상태 양호, 패킷 손실 없음.
-   **스위치 (SW-FLOOR-03)**
    1.  ^ 포트 일부 비활성화 상태 발견 (3번, 7번 포트).
        -   % 원인 파악 및 필요시 교체 진행 예정.
    2.  (점검 특이사항) 냉각팬 소음 다소 크게 발생.

## 3. 보안 시스템 점검 결과

-   **방화벽 (FW-EXTERNAL)**
    -   = 정책 최적화 작업 완료, 로그 분석 강화.
    -   // (참고) 최근 30일간 외부 침입 시도 0건.
-   **백신 중앙 관리 시스템**
    1.  `[업데이트 상태]` 전체 PC 최신 버전 유지율 98%.
        -   ! 미 업데이트 PC(5대) 현황 파악 및 조치 요망.
    2.  `* 신규 악성코드 패턴` 긴급 업데이트 완료.

## 4. 사용자 PC 및 주변기기

-   // (부서별 요청사항 취합)
    1.  `@기획팀`: 노후 프린터(HP-1234) 교체 요청.
    2.  `#총무팀`: 스캐너 드라이버 오류, 재설치 지원 요청.
    3.  `?민원여권과`: 일부 PC 속도 저하 문제 해결 요청.
        -   (조치) 금주 내 방문 점검 및 최적화 예정.
```

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 시도
3. 변환 결과 확인:
   - **모든 템플릿에서 동일한 치명적 오류 발생:**
     * "알 수 없는 오류" 메시지 표시
     * HWP 파일이 생성되지 않거나 빈 파일 생성
     * 프로그램이 중단되거나 응답 없음 상태 발생
     * 변환 과정에서 완전히 실패하여 결과물 확인 불가

### 구체적인 문제 상황:
1. **기대되는 결과:**
   - 특수문자가 포함된 목록도 정상적으로 변환되어야 함
   - IT 점검 보고서의 표준 형식이 유지되어야 함
   - 특수문자 표기법이 그대로 또는 적절히 변환되어 표시되어야 함
   - 문서 전체가 정상적으로 변환 완료되어야 함

2. **실제 발생하는 결과:**
   - "알 수 없는 오류" 발생으로 변환 완전 실패
   - HWP 파일이 생성되지 않음
   - 프로그램 오류로 인한 중단 또는 무응답
   - 어떤 내용도 확인할 수 없는 완전한 변환 실패
   - 재시도해도 동일한 오류 반복 발생

### 오류를 유발하는 특수문자 패턴:
1. **경고/주의 표시 문자**
   - `!` (느낌표) - 경고나 중요 사항 표시
   - `?` (물음표) - 확인 필요 사항 표시
   - `*` (별표) - 강조나 중요도 표시

2. **시스템/기술 관련 문자**
   - `@` (앳마크) - 담당자나 위치 표시
   - `#` (해시태그) - 카테고리나 분류 표시
   - `//` (슬래시) - 주석이나 참고사항 표시

3. **상태/관계 표시 문자**
   - `+` (플러스) - 추가나 긍정적 상태
   - `&` (앰퍼샌드) - 연결이나 그리고의 의미
   - `<` `>` (부등호) - 비교나 방향 표시

4. **기타 특수 문자**
   - `^` (캐럿) - 위치나 지시 표시
   - `%` (퍼센트) - 비율이나 진행률 표시
   - `=` (등호) - 동등이나 결과 표시
   - `` ` `` (백틱) - 코드나 시스템명 표시
   - `(` `)` (괄호) - 부연설명이나 분류

### 특히 문제가 되는 상황:
1. **IT 시스템 점검 보고서**
   - 서버, 네트워크 장비 상태 표시에 특수문자 필수 사용
   - 기술적 내용 표현에 다양한 기호 활용이 일반적
   - 변환 실패로 인해 중요한 점검 결과를 문서화할 수 없음

2. **시스템 매뉴얼 및 가이드**
   - 명령어, 설정값, 상태 표시에 특수문자 다수 사용
   - 기술 문서의 표준 표기법이 적용 불가
   - 업무 연속성에 심각한 지장 초래

3. **장비 관리 및 유지보수 문서**
   - 장비 상태, 오류 코드, 조치 사항에 기호 사용 빈번
   - 정확한 기술적 표현이 불가능해져 업무 품질 저하
   - 전문적인 문서 작성이 원천적으로 봉쇄됨

4. **프로젝트 관리 및 체크리스트**
   - 진행 상태, 우선순위, 카테고리 구분에 특수문자 활용
   - 시각적 구분과 정보 전달이 완전히 차단됨

### 예상되는 원인:
1. **마크다운 파서의 특수문자 처리 오류**
   - 특정 특수문자가 마크다운 문법과 충돌하여 파싱 실패
   - 예외 처리되지 않은 문자 조합으로 인한 시스템 오류

2. **HWPML 변환 엔진의 문자 인코딩 문제**
   - 특수문자의 유니코드 변환 과정에서 오류 발생
   - 지원되지 않는 문자에 대한 에러 핸들링 부재

3. **정규식 처리 과정의 예외 상황**
   - 특수문자 패턴 매칭 과정에서 무한루프 또는 오류 발생
   - 이스케이프 처리되지 않은 특수문자로 인한 파싱 실패

4. **템플릿 매핑 과정의 오류**
   - 특수문자가 포함된 텍스트를 HWPML 요소로 변환 시 실패
   - 예상하지 못한 문자 조합에 대한 처리 로직 부재

### 심각도:
- 🐛 심각 (Critical)
- 🚫 변환 실패
- **가장 치명적인 수준의 버그** - 문서 전체를 사용할 수 없게 만듦
- IT 관련 업무 문서 작성이 완전히 불가능
- 모든 템플릿에서 동일한 오류로 대체 방안 전혀 없음
- 특수문자가 포함된 어떤 기술 문서도 변환할 수 없음
- 업무 연속성에 심각한 지장을 초래하는 치명적 결함
- 프로그램의 기본 기능을 완전히 무력화시키는 심각한 안정성 문제

### 임시 해결 방안:
1. **특수문자 사전 제거**
   - 변환 전 모든 특수문자를 일반 텍스트로 치환
   - 예: `!` → `[주의]`, `@` → `[담당]` 등

2. **문서 분할 작업**
   - 특수문자가 포함된 부분을 별도 처리하여 변환
   - 수동으로 한글 문서에서 특수문자 재입력

3. **대체 표기법 사용**
   - 특수문자 대신 한글 또는 영문 표기 사용
   - 문서의 전문성은 떨어지지만 변환 가능

### 근본적 해결 방안 제안:
1. **특수문자 예외 처리 강화**
   - 모든 특수문자에 대한 안전한 파싱 로직 구현
   - 오류 발생 시 적절한 에러 핸들링 및 대체 처리

2. **마크다운 파서 개선**
   - 특수문자와 마크다운 문법의 충돌 방지 로직 추가
   - 이스케이프 처리 및 문자 인코딩 안정성 강화

3. **변환 엔진 안정성 향상**
   - 예외 상황에서도 부분적으로라도 변환이 가능하도록 개선
   - 오류 발생 부분을 건너뛰고 나머지 내용 변환 기능 구현

4. **사용자 알림 시스템**
   - 어떤 특수문자가 문제를 일으키는지 명확한 오류 메시지 제공
   - 변환 전 특수문자 검사 및 경고 기능 추가
