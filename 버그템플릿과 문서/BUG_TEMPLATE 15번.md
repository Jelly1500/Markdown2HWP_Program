# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에서 빈 줄로 구분된 단락들이 한글 문서로 변환될 때 구분이 무시되고 하나의 연속된 텍스트로 변환되는 현상이 발생합니다. 이는 문서의 가독성을 크게 해치고, 특히 공문서나 법적 문서와 같이 명확한 단락 구분이 중요한 문서에서 심각한 문제가 됩니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 개인정보 처리방침 변경 안내
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
# 개인정보 처리방침 변경 안내

항상 저희 서비스를 이용해주시는 고객님께 깊은 감사를 드립니다.
고객님의 개인정보를 더욱 안전하게 보호하고, 관련 법규 변경 사항을 반영하기 위하여 개인정보 처리방침이 아래와 같이 개정됨을 안내드립니다.
본 개정 사항을 확인하시어 서비스 이용에 참고하시기 바랍니다.

1. 주요 개정 내용
   - 개인정보의 수집 및 이용 목적 구체화
   - 개인정보의 제3자 제공에 관한 사항 명확화
   - 개인정보 보유 및 이용 기간 변경 (일부 항목)


2. 변경된 개인정보 처리방침의 효력 발생일
   개정된 개인정보 처리방침은 2025년 7월 1일부터 효력이 발생됩니다.
   
3. 이의제기 및 문의
   
   개정된 개인정보 처리방침 내용에 대한 문의사항이나 이의가 있으신 경우, 고객센터(123-4567) 또는 개인정보보호 담당자(privacy@example.go.kr)에게 연락 주시면 성실히 답변드리겠습니다.
```

<br><br>

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - 모든 템플릿에서 동일한 문제 발생:
     * 단락 구분이 무시되어 텍스트가 연속적으로 이어짐
     * 예시:
       ```
       2. 변경된 개인정보 처리방침의 효력 발생일개정된 개인정보 처리방침은 2025년 7월 1일부터 효력이 발생됩니다.3. 이의제기 및 문의
       ```
     * 빈 줄로 구분된 단락이 모두 하나로 합쳐짐
     * 목록 항목 간의 구분도 불명확해짐
   - 문서의 구조적 가독성이 크게 저하됨
   - 법적 문서로서의 명확성이 훼손됨

### 예상되는 원인:
1. 마크다운의 빈 줄을 단락 구분자로 인식하지 못하는 파서 문제
2. HWPML 변환 시 단락 구분 태그 생성 로직 부재
3. 연속된 빈 줄을 하나의 빈 줄로 압축하는 처리 로직
4. 공식 문서 형식에 맞는 단락 구분 스타일 정의 누락
5. 단락 간 간격을 조절하는 설정이 기본값으로 고정됨
