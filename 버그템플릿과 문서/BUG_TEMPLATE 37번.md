# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에 **Python, JavaScript, Java, C++ 등 프로그래밍 언어의 코드 블록**이 포함되어 있을 때, **문법 하이라이팅**, **들여쓰기 보존**, **주석 구분**, **키워드 강조**, **문자열 처리** 등의 **기본적인 코드 서식이 완전히 무시**되어 **일반 텍스트로만 처리**되는 심각한 문제입니다. 이로 인해 **개발 문서, 기술 매뉴얼, 프로그래밍 교육 자료, API 문서** 등에서 **핵심적인 코드 가독성과 이해도가 완전히 상실**되어 **현대 IT 업무 환경의 필수 문서화 기능**이 **원천적으로 불가능**한 치명적 결함입니다.

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 프로그래밍 코드: Python 피보나치 수열 구현 (재귀 + 메모이제이션)
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml

   - 새템플릿.hml

   - 템플릿문서1.hml

테스트한 Python 코드 블록:
```python
def fibonacci(n, memo=None):
    """
    n번째 피보나치 수를 반환합니다.
    메모이제이션을 통해 중복 계산을 줄입니다.
    """
    if memo is None:
        memo = {}
    if n in memo:
        return memo[n]
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    # 재귀 호출 + 결과 저장 (메모이제이션)
    memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo)
    return memo[n]

if __name__ == "__main__":
    # 사용자 입력으로 n값을 받아 n번째 피보나치 수 출력
    try:
        n = int(input("몇 번째 피보나치 수를 계산할까요? "))
        result = fibonacci(n)
        print(f"{n}번째 피보나치 수는 {result}입니다.")
    except ValueError:
        print("정수를 입력해주세요.")
```

## 어떤 과정에서 버그가 발생했나요?

1. 위 Python 코드를 마크다운 코드 블록으로 포함하여 저장
2. 각각의 템플릿으로 변환 시도
3. **모든 템플릿에서 동일한 심각한 서식 미지원 문제 발생:**
   - **문법 하이라이팅 완전 무시**
   - **들여쓰기 구조 왜곡 또는 소실**
   - **주석과 코드 구분 불가능**
   - **키워드, 함수명, 변수명 구분 없음**

### 구체적인 문제 상황:
1. **기대되는 결과:**
   - **키워드 강조**: `def`, `if`, `elif`, `return`, `try`, `except` 등이 **굵게** 또는 **색상 구분**
   - **문자열 처리**: `"몇 번째 피보나치 수를 계산할까요? "` 등이 **별도 색상**으로 표시
   - **주석 구분**: `# 재귀 호출 + 결과 저장` 등이 **회색** 또는 **이탤릭**으로 구분
   - **DocString 처리**: `"""..."""` 블록이 **문서화 문자열**로 인식
   - **들여쓰기 보존**: **4칸 들여쓰기**가 **정확히 유지**되어 **코드 구조 명확화**
   - **함수명 강조**: `fibonacci`, `input`, `print` 등 **함수 호출 구분**

2. **실제 발생하는 결과:**
   - **모든 텍스트가 동일한 서식**으로 **구분 없이** 표시
   - **들여쓰기가 무작위로 변형**되거나 **완전히 소실**
   - **주석과 실행 코드**가 **시각적으로 구분 불가능**
   - **키워드, 변수명, 함수명**이 **모두 동일한 폰트와 색상**
   - **코드의 논리적 구조 파악 극도로 어려움**
   - **가독성 완전 상실**로 **학습 및 이해 불가능**

### 손실되는 핵심 코드 서식 요소들:
1. **문법 하이라이팅 (Syntax Highlighting)**
   ```python
   # 기대: 키워드 강조

   # 실제: 모든 텍스트 동일 서식
   def fibonacci(n, memo=None):  # 모든 글자가 똑같이 표시
       if n <= 0:               # 구분 없음
           return 0             # 구분 없음
   ```

2. **들여쓰기 구조 보존**

   ```python
       if n in memo:             # 1단계 들여쓰기
           return memo[n]
       if n <= 0:                # 1단계 들여쓰기
           return 0

   def fibonacci(n, memo=None):
   if memo is None:              # 들여쓰기 무시
   memo = {}
   if n in memo:                 # 구조 파괴
   return memo[n]
   ```

3. **주석 및 DocString 처리**

   ```python
   """
   # 재귀 호출 + 결과 저장 (메모이제이션)     # 인라인 주석
   
   # 실제: 주석과 코드 구분 없음
   """
   n번째 피보나치 수를 반환합니다.        # 일반 텍스트와 동일
   메모이제이션을 통해 중복 계산을 줄입니다.  # 구분 불가능
   """
   # 재귀 호출 + 결과 저장 (메모이제이션)     # 일반 텍스트와 동일
   ```
