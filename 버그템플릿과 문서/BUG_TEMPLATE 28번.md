# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서의 **목록 항목 내부에 복합적인 링크 그룹**이 포함되어 있을 때, "**알 수 없는 오류**"가 발생하며 변환이 **완전히 실패**하는 치명적인 문제입니다. 특히 **파이프(|)로 연결된 링크들, 참조 링크 정의, 링크 제목 속성, URL 내 특수문자** 등이 복합적으로 사용된 경우 파싱 엔진이 이를 처리하지 못해 전체 변환이 중단됩니다. 이는 **정부기관 바로가기, 포털 사이트 모음, 관련 링크 그룹** 등을 정리한 **공공 안내 문서나 업무 매뉴얼**에서 매우 빈번하게 사용되는 패턴으로, 이러한 문서들의 변환이 **완전히 불가능**해지는 심각한 결함입니다.

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 시도
3. 변환 결과 확인:
   - **모든 템플릿에서 동일한 치명적 오류 발생:**
     * "알 수 없는 오류" 메시지 표시
     * HWP 파일이 생성되지 않거나 빈 파일 생성
     * 프로그램이 중단되거나 응답 없음 상태 발생
     * 변환 과정에서 완전히 실패하여 결과물 확인 불가

### 구체적인 문제 상황:
1. **기대되는 결과:**
   - 다양한 링크 문법들이 적절한 하이퍼링크로 변환되어야 함
   - 파이프로 연결된 링크 그룹들이 구분되어 표시되어야 함
   - 참조 링크들이 올바른 URL로 연결되어야 함
   - 링크 제목 속성들이 툴팁이나 부가 정보로 표시되어야 함
   - 정부기관 바로가기 문서로서 기본 기능을 해야 함

2. **실제 발생하는 결과:**
   - "알 수 없는 오류" 발생으로 변환 완전 실패
   - HWP 파일이 생성되지 않음
   - 프로그램 오류로 인한 중단 또는 무응답
   - 어떤 내용도 확인할 수 없는 완전한 변환 실패
   - 재시도해도 동일한 오류 반복 발생

### 특히 문제가 되는 상황:
1. **정부기관 바로가기 문서**
   - 공공기관에서 매우 빈번하게 작성하는 문서 유형
   - 여러 관련 사이트를 그룹핑하여 안내하는 것이 일반적
   - 변환 불가로 인해 시민 서비스 제공 차질

2. **포털 사이트 모음 안내**
   - 업무 매뉴얼에서 관련 시스템들을 묶어서 안내
   - 사용자 편의를 위한 링크 그룹핑이 필수적
   - 전체 문서 변환 실패로 업무 효율성 심각 저하

3. **공공데이터 및 서비스 안내**
   - 디지털 정부 서비스 홍보 및 안내 문서
   - 복수의 관련 포털을 함께 제시하는 것이 표준
   - 공공 정보 제공의 기본 기능 마비

4. **교육 및 참고자료 링크 모음**
   - 직원 연수, 시민 교육용 참고자료 정리
   - 카테고리별로 관련 링크들을 그룹화하여 제공
   - 교육 효과 및 정보 접근성 크게 손상

### 예상되는 원인:
1. **복합 링크 구문 파싱 실패**
   - 파이프(|)로 연결된 링크 그룹을 처리하지 못함
   - 마크다운 파서가 복수 링크를 단일 구문으로 오인
   - 링크 구분자에 대한 처리 로직 부재

2. **참조 링크 해석 오류**
   - 문서 하단의 링크 정의와 본문의 참조 연결 실패
   - `[텍스트][참조ID]` 형식의 매칭 로직 오류
   - 참조 링크 정의 파싱 과정에서 예외 발생

3. **URL 특수문자 처리 문제**
   - `?`, `&`, `=` 등 쿼리 파라미터 처리 실패
   - 긴 URL과 복잡한 경로 구조 파싱 오류
   - URL 인코딩/디코딩 과정에서 오류 발생

4. **링크 제목 속성 처리 오류**
   - `[텍스트](URL "제목")` 형식의 제목 속성 파싱 실패
   - 따옴표 처리 과정에서 문자열 파싱 오류
   - 제목 속성과 URL 분리 로직 부재

5. **중첩된 마크다운 구문 충돌**
   - 목록 내부의 복잡한 링크 구문 처리 한계
   - 인용구, 목록, 링크가 중첩된 구조 파싱 실패
   - 다층 구조의 마크다운 문법 해석 오류

### 심각도:
- 🐛 심각 (Critical)
- 🚫 변환 실패
- **절대 최고 심각도** - 공공 안내 문서 작성 완전 불가능
- 정부기관 바로가기, 포털 모음 등 핵심 업무 문서 변환 차단
- 시민 서비스 제공을 위한 기본 문서 작성 원천 봉쇄
- 모든 템플릿에서 동일한 오류로 대체 방안 전혀 없음
- 공공기관의 디지털 서비스 안내 기능 완전 무력화
- 현대적 웹 문서의 표준적 링크 사용 패턴과 완전히 불일치
- 복수 관련 사이트 안내라는 기본적 문서 작성 요구사항 미충족

### 임시 해결 방안:
1. **링크 그룹 분리**
   - 파이프로 연결된 링크들을 별도 목록 항목으로 분할
   - 예: `[링크1](URL1) | [링크2](URL2)` → 별도 줄로 각각 작성
   - 링크 그룹핑 효과는 상실되지만 기본 변환은 가능

2. **참조 링크를 인라인 링크로 변환**
   - `[텍스트][참조]` → `[텍스트](URL)` 형식으로 변경
   - 문서 하단의 참조 정의 부분 삭제
   - 가독성은 다소 떨어지지만 변환 성공률 향상

3. **링크 제목 속성 제거**
   - `[텍스트](URL "제목")` → `[텍스트](URL)` 로 단순화
   - 부가 정보는 손실되지만 기본 링크 기능 유지
   - 필요시 제목 정보를 별도 텍스트로 표기

4. **복잡한 URL 단순화**
   - 긴 쿼리 파라미터가 포함된 URL을 단축 URL로 변경
   - 또는 대표 페이지 URL로 대체하여 안정성 확보
   - URL 특수문자로 인한 파싱 오류 회피

### 근본적 해결 방안 제안:
1. **고급 링크 파서 구현**
   - 다양한 마크다운 링크 문법을 종합적으로 처리하는 파서
   - 파이프 구분자, 참조 링크, 제목 속성 등을 안정적으로 처리
   - CommonMark 표준을 완전히 지원하는 파싱 엔진 도입

2. **링크 그룹 처리 시스템**
   - 파이프로 연결된 링크들을 개별 링크로 분리 처리
   - 그룹 단위 링크를 HWPML에서 적절히 표현하는 방법 구현
   - 사용자가 링크 그룹 처리 방식을 선택할 수 있는 옵션

3. **URL 안정화 시스템**
   - 복잡한 URL과 특수문자를 안전하게 처리하는 시스템
   - URL 유효성 검증 및 자동 인코딩 기능
   - 긴 URL에 대한 예외 처리 및 대체 방안 제공

4. **참조 링크 전처리 시스템**
   - 문서 분석을 통해 참조 링크를 인라인 링크로 자동 변환
