# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에서 들여쓰기나 공백이 많은 텍스트가 한글 문서로 변환될 때 완전히 누락되는 현상이 발생합니다. 시나 예술적 텍스트에서 의도적으로 사용하는 공백과 들여쓰기가 보존되지 않아 작품의 의도가 훼손됩니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 고요한 새벽 (시)
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
# 고요한 새벽

창가에     기대어
새벽을     본다.

아직     어둠이     남아있다.

        새 한 마리
        날아간다.
            저 멀리.

곧     해가     뜨겠지.

    오늘은 또 어떤 하루일까.
    문득,     그런     생각이     든다.

조용하다.
참     조용하다.
```

<br><br>

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - 모든 템플릿에서 동일한 문제 발생:
     * 정상적으로 변환된 부분:
       ```
       고요한 새벽
       
       창가에     기대어새벽을     본다.
       아직     어둠이     남아있다.
       곧     해가     뜨겠지.
       조용하다.참     조용하다.
       ```
     * 완전히 누락된 부분:
       ```
       새 한 마리
               날아간다.
                   저 멀리.
       
       오늘은 또 어떤 하루일까.
           문득,     그런     생각이     든다.
       ```
   - 특히 들여쓰기가 많은 행이나 공백이 연속된 부분이 누락됨
   - 시의 시각적 구조와 의도가 훼손됨

### 예상되는 원인:
1. 마크다운 파서가 과도한 공백이나 들여쓰기를 무시하는 설정
2. HWPML 변환 시 연속된 공백을 단일 공백으로 처리하는 로직
3. 들여쓰기 수준이 특정 임계값을 넘으면 해당 텍스트를 무시하는 문제
4. 공백 문자 처리 시 특수한 경우(예: 시 형식)를 고려하지 않는 로직
