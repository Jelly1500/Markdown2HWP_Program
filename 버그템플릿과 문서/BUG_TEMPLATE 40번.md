# 버그 리포트

## 어떤 버그인가요?

> **공공기관 정보공개 운영지침**과 같은 **12단계 깊은 중첩 구조** 문서에서 **3단계까지만 제대로 표시**되고 **그 이후 깊이는 처리 실패**하는 심각한 버그입니다. **법령, 지침, 규정** 등 **공공기관 핵심 업무 문서**는 **헤더와 목록이 혼합된 복잡한 계층 구조**가 필수이며, **조항 → 항 → 호 → 목 → 가 → 나** 등 **6단계 이상 중첩**이 일반적임에도 불구하고 **구조적 표현이 원천적으로 불가능**한 치명적 결함입니다.

## 실제로 뭐가 잘못되었나요?

### 🔍 **중첩 구조 세부 분석**
```
1단계: # (헤더1) - ✅ 정상
2단계: ## (헤더2) - ✅ 정상  
3단계: ### (헤더3) - ✅ 정상
4단계: 1. (순서목록) - ❌ 처리 실패 시작
5단계: - (비순서목록) - ❌ 처리 실패
6단계: 1. (순서목록) - ❌ 처리 실패
7단계: - (비순서목록) - ❌ 처리 실패
8단계: * (비순서목록) - ❌ 처리 실패
9단계: 1. (순서목록) - ❌ 처리 실패
10단계: - (비순서목록) - ❌ 처리 실패
11단계: * (비순서목록) - ❌ 처리 실패
12단계: - (비순서목록) - ❌ 처리 실패
```

### 📄 **실제 중첩 경로 예시**
```
# → ## → ### → 1. → - → 1. → - → * → 1. → - → * → 1. → -
```

### 💥 **영향받는 요소**
1. **들여쓰기 깊이**: 4칸 → 8칸 → 12칸 등 증가
2. **목록 마커 혼합**: 1. / - / * 등 다양한 마커
3. **텍스트 내용**: 공공기관 전문 용어 및 법조문 번호
4. **복합 구조**: 헤더 + 목록 혼합 중첩

## 원래는 어떻게 되어야 하나요?

### ✅ **기대되는 정상 동작**
1. **12단계 깊은 중첩**: 모든 단계의 계층 구조 정확한 표현
2. **법령 문서 구조**: 조항 → 항 → 호 → 목 → 가 → 나 등 6단계 이상 지원
3. **들여쓰기 일관성**: 각 단계별 적절한 들여쓰기 및 마커 표시
4. **시각적 구분**: 상하위 관계가 명확하게 구분되는 렌더링

### 🏢 **공공기관 업무 필수 요구사항**
- **법령 및 규정 문서**: 대부분 5단계 이상 중첩 필요
- **업무 매뉴얼**: 대분류 → 중분류 → 소분류 → 세부절차
- **조직 운영 규정**: 부서 → 팀 → 담당 → 업무 → 세부사항

### 🎯 **공공기관 적용 시나리오**
1. **법령 및 규정 문서**
   - 법률 → 시행령 → 시행규칙 → 세부지침
   - 조항 → 항 → 호 → 목 → 가 → 나 (6단계 이상)

2. **업무 매뉴얼**
   - 대분류 → 중분류 → 소분류 → 세부절차
   - 각 단계별 체크리스트 및 주의사항

3. **조직 운영 규정**
   - 부서 → 팀 → 담당 → 업무 → 세부사항
   - 직무분장 및 권한 위임 체계

### 💡 **개선 방안 제안**
1. **중첩 깊이 제한 해제**: 현재 3단계 → 최소 10단계 지원
2. **들여쓰기 알고리즘 개선**: 가변 깊이 처리 로직 강화
3. **마커 인식 확장**: 다양한 목록 마커 조합 처리
