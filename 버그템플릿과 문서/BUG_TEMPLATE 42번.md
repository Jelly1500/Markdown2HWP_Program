# 버그 리포트

## 어떤 버그인가요?

> **K-SDGs 로드맵**과 같은 **복잡한 공공기관 정책 문서**에서 **표 렌더링 이상 출력** 및 **HTML 태그, Mermaid 다이어그램** 등 **고급 양식이 미반영**되는 버그입니다. **다부처 통합 로드맵**, **국가 지속가능발전 목표** 등 **복합 구조의 정책 문서**에는 **표 내 HTML 태그**, **정의 목록**, **접기/펼치기 요소**, **플로우차트** 등이 필수적으로 사용되지만 **전혀 지원되지 않아** **정책 문서 작성의 표현력이 심각하게 제약**됩니다.

<br><br>

2. **테스트 문서**: 2030 국가 지속가능발전 목표(K-SDGs) 이행을 위한 다부처 통합 로드맵 (초안)

   - 새템플릿.hml ❌ 표 및 HTML 태그 렌더링 문제

## 실제로 뭐가 잘못되었나요?

### ✅ **정상 처리되는 요소들**
1. **기본 마크다운 구조**: 헤더 계층 구조, 기본 목록 및 중첩 목록, 텍스트 서식
2. **각주 시스템**: `[^sdg_def]`, `[^coop_tasks]` 등 각주 참조 및 정의 블록 처리
3. **코드 블록**: JSON 형식 코드 블록, 언어별 구문 강조 지원
4. **체크박스 목록**: `- [x]`, `- [ ]` 형태 정상 표시

### ❌ **문제가 되는 요소들**
1. **표(테이블) 렌더링 문제**
   ```markdown
   | 구분       | 2024년 현황 | 2030년 목표 | 비고                                  |
   | :--------- | :----------: | :----------: | :------------------------------------ |
   | 전기차 보급 |   10만 대    |   100만 대   | 충전 인프라 동시 확충 필수            |
   | 자전거 도로 |   500 km     |   1,500 km   | <u>안전성 확보</u> 및 편의시설 증진 |
   ```
   - 표 내부의 HTML 태그 (`<u>`) 처리 실패
   - 열 정렬 및 셀 내용 표시 이상

2. **HTML 태그 미지원**
   - `<u>실패 가능성을 용인</u>` - 밑줄 태그
   - `<dl>`, `<dt>`, `<dd>` - 정의 목록 태그
   - `<details>`, `<summary>` - 접기/펼치기 태그
   - `<p>`, `<ul>`, `<li>` - 기본 HTML 구조 태그

3. **Mermaid 다이어그램**
   ```mermaid
   graph TD
       A(돌봄 필요 발생) --> B{통합지원센터 상담};
   ```
   - 플로우차트 시각화 미지원

### 💥 **복합 구조에서의 처리 한계**
- **12단계 깊은 중첩**: 일부 깊이에서 구조 손실 (기존 BUG 40번과 관련)
- **HTML과 마크다운 혼합**: 혼합 사용 시 렌더링 불안정
- **표 내 복잡 요소**: 표 셀 내부의 HTML 태그나 링크 처리 문제

<br><br>

## 원래는 어떻게 되어야 하나요?

### ✅ **기대되는 정상 동작**
1. **표 내 HTML 태그**: 셀 내부의 `<u>`, `<mark>`, `<strong>` 등 정상 렌더링
2. **정의 목록 지원**: `<dl>`, `<dt>`, `<dd>` 태그로 용어 정의 표현
3. **접기/펼치기 요소**: `<details>`, `<summary>` 태그로 정보 계층화
4. **다이어그램 렌더링**: Mermaid 플로우차트의 시각적 표현

### 🎯 **정책 문서 필수 요구사항**
- **국민 소통 자료**: 정책 설명 자료의 시각적 표현력 확보
- **부처 간 협업 문서**: 복합 구조의 정보 체계적 표현
- **국제기구 제출 문서**: 표준화된 형식 요구사항 충족

<br><br>

## 추가적으로 도움이 될 만한 정보가 있나요?

### 📄 **테스트 문서 구조 예시**
```markdown
# 2030 국가 지속가능발전 목표(K-SDGs) 이행을 위한 다부처 통합 로드맵 (초안)

## 제1부: 서론 및 추진 배경

### 1.1. 국제 동향 및 K-SDGs의 중요성
지속가능발전 목표(SDGs)[^sdg_def]는 전 지구적 과제 해결을 위한 국제사회의 공동 약속입니다.

[^sdg_def]: SDGs (Sustainable Development Goals): 2015년 UN 총회에서 채택된 의제
    <dl>
      <dt>주요 요소</dt>
      <dd>참여, 투명성, 책임성, 효과성, 형평성</dd>
      <dt>기대 효과</dt>
      <dd>정책 결정의 민주성 및 효율성 증대</dd>
    </dl>

### 2.1. 환경 분야 (E: Environment)

1.  **탄소중립 사회로의 전환 가속화**
    -   수송 부문:
        * 친환경 자동차 보급률 50% 달성.
            | 구분       | 2024년 현황 | 2030년 목표 | 비고                                  |
            | :--------- | :----------: | :----------: | :------------------------------------ |
            | 전기차 보급 |   10만 대    |   100만 대   | 충전 인프라 동시 확충 필수            |
            | 자전거 도로 |   500 km     |   1,500 km   | <u>안전성 확보</u> 및 편의시설 증진 |

2.  **국민 참여 플랫폼 활성화**
    <details>
      <summary>플랫폼 주요 기능 (클릭하여 펼치기)</summary>
      <p>국민 누구나 K-SDGs 이행과 관련된 의견을 제시하고, 관련 정보를 얻으며, 토론에 참여할 수 있는 온라인 공간입니다.</p>
      <ul>
        <li>정책 제안 및 숙의 토론</li>
        <li>이행 현황 모니터링 (데이터 시각화 제공)</li>
        <li>우수사례 공유 및 확산</li>
      </ul>
    </details>

    -   지역사회 통합 돌봄(커뮤니티 케어) 서비스 확산.
        -   의료-요양-주거 연계 서비스 모델 개발.
            ```mermaid
            graph TD
                A(돌봄 필요 발생) --> B{통합지원센터 상담};
                B --> C[욕구 사정 및 계획 수립];
                C --> D[의료 서비스 연계];
                C --> E[요양/주거 서비스 연계];
                C --> F[기타 생활 지원];
            ```
```

### 🏢 **공공기관 업무 영향도**
1. **정책 문서 작성 한계**
   - K-SDGs, 국정과제 등 복잡한 정책 로드맵 작성 제약
   - 다부처 통합 문서의 구조적 표현 어려움
   - 정책 지표 및 성과 표 작성 문제

2. **국민 소통 자료 제작 한계**
   - 정책 설명 자료의 시각적 표현 부족
   - 대화형 요소 (접기/펼치기 등) 미지원
   - 복잡한 정보의 단계적 공개 방식 불가

3. **부처 간 협업 문서 한계**
   - 여러 부처 공동 작성 문서의 복합 구조 처리 문제
   - 표준화된 정부 문서 형식과의 호환성 부족
   - 국제기구 제출 문서 형식 요구사항 충족 어려움

### 💡 **단계적 개선 방안**
1. **1단계: 핵심 HTML 태그 지원**
   - 기본 태그: `<u>`, `<mark>`, `<sup>`, `<sub>`
   - 구조 태그: `<dl>`, `<dt>`, `<dd>`

2. **2단계: 고급 요소 지원**
   - 접기/펼치기: `<details>`, `<summary>`
   - 표 내 복합 요소 처리 개선

3. **3단계: 다이어그램 지원**
   - Mermaid 플로우차트 렌더링
   - 기타 시각화 도구 연동

### 📝 **사용자 의견**
> **"매우 복잡한 구조인데, 표가 좀 이상하게 나오고 html 양식이 제대로 반영안되는 문제가있네. 그외는 괜찮은듯"**

이는 **정책 문서 작성의 표현력 제약**으로 **공공기관 업무 효율성에 직접적 영향**을 미치는 중요한 기능입니다.
