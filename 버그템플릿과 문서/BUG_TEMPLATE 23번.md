# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에서 이모지(이모티콘)를 사용한 목록이나 텍스트가 한글 문서로 변환 시 이모지가 **깨지거나 완전히 사라지거나 물음표(?)로 표시**되는 문제가 발생합니다. 특히 **이모지로 시작하는 목록 항목**에서 이 문제가 두드러지며, 현대적인 문서 작성에서 중요한 시각적 요소인 이모지가 제대로 표시되지 않아 문서의 가독성과 직관성이 크게 저하됩니다. 목록 구조 자체는 정상적으로 변환되지만 이모지 표시 문제로 인해 문서의 완성도가 떨어지는 상황입니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 부서별 주간 주요 업무 추진 현황 (2025년 6월 1주차)
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
# 부서별 주간 주요 업무 추진 현황 (2025년 6월 1주차)

## 1. 기획조정실

-   ✅ 2025년도 하반기 주요업무계획 수립 완료
    -   📝 최종 보고서 인쇄 및 배부 준비 중
    -   💡 차주 부서장 회의 시 보고 예정
-   ⚠️ 신규 사업 타당성 검토 관련 외부 자문 지연
    -   전문가 일정 조율 후 금주 내 재추진

## 2. 자치행정과

1.  👍 주민자치센터 프로그램 만족도 조사 결과 취합 완료
    -   📊 분석 보고서 작성 착수 (6월 10일 완료 목표)
    -   🤔 개선 필요사항 도출 및 의견 수렴 예정
2.  🔄 청사 시설 안전 점검 실시 (6월 2일 ~ 6월 4일)
    -   🛠️ 노후 시설 일부 보수 작업 즉시 시행
    -   📋 점검 결과 보고서 작성 중

## 3. 정보화정책과

-   🚀 차세대 그룹웨어 시스템 도입 준비
    -   1단계: 요구사항 분석 및 설계 검토
        -   ✅ 사용자 인터뷰 완료 (5개 부서 대상)
        -   📄 설계 문서 초안 검토 중
    -   2단계: 개발 업체 선정 공고 예정
        -   📝 RFP(제안요청서) 최종 검토 단계
-   💻 개인정보보호 강화 교육 실시 (전 직원 대상)
    -   교육 만족도: **매우 높음** (설문 결과)

## 4. 문화관광과

1.  ✨ 여름맞이 지역 축제 기획안 확정
    -   📅 주요 일정: 2025년 7월 20일 ~ 7월 22일
    -   섭외 관련:
        1.  🎤 초청 가수 및 공연팀 계약 완료
        2.  🎪 체험 부스 운영 업체 모집 공고 게시
2.  🚧 역사 유적지 탐방로 정비 사업 진행
    -   현재 공정률 70%
    -   🌧️ 우기 대비 안전 점검 강화

## 5. 기타 협조 사항

-   ♻️ 각 부서에서는 폐지 및 재활용품 분리수거 철저 요청드립니다.
-   🔒 정보 보안 강화 주간입니다. 개인 PC 및 자료 관리에 유의 바랍니다.
```

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - 모든 템플릿에서 동일한 문제 발생:
     * 변환 자체는 성공하여 HWP 파일이 생성됨
     * 목록 구조는 정상적으로 유지됨
     * 하지만 이모지 표시에서 다음과 같은 문제 발생:
       - 이모지가 완전히 사라짐
       - 이모지가 물음표(?) 또는 네모박스(□)로 표시됨
       - 일부 이모지는 깨진 글자로 표시됨
       - 한글 텍스트는 정상이지만 이모지만 문제 발생

### 구체적인 문제 상황:
1. **기대되는 결과:**
   - ✅ 체크마크가 정상적으로 표시되어야 함
   - 📝 메모 이모지가 정상적으로 표시되어야 함
   - 💡 전구 이모지가 정상적으로 표시되어야 함
   - 기타 모든 이모지가 원래 모양 그대로 표시되어야 함
   - 이모지로 인한 시각적 구분 효과가 유지되어야 함

2. **실제 발생하는 결과:**
   - 이모지가 물음표(?)로 표시됨
   - 이모지가 완전히 사라져서 텍스트만 남음
   - 이모지가 네모박스(□) 또는 깨진 문자로 표시됨
   - 시각적 구분 효과가 완전히 상실됨
   - 문서의 직관성과 가독성이 크게 저하됨

### 영향을 받는 이모지 유형:
1. **업무 상태 표시 이모지**
   - ✅ (완료), ⚠️ (주의), 🔄 (진행중) 등
   - 업무 상태를 한눈에 파악하기 어려워짐

2. **카테고리 구분 이모지**
   - 📝 (문서), 📊 (데이터), 💻 (IT) 등
   - 업무 유형별 구분이 불가능해짐

3. **일정 관련 이모지**
   - 📅 (달력), ⏰ (시간), 🗓️ (일정) 등
   - 일정 정보의 시각적 구분 실패

4. **감정/평가 표시 이모지**
   - 👍 (좋음), 🤔 (고민), ✨ (우수) 등
   - 평가나 감정 표현이 불가능해짐

5. **기타 시각적 구분 이모지**
   - 🚀 (새로운), 🛠️ (수리), 🔒 (보안) 등
   - 중요도나 특성 구분이 어려워짐

### 특히 문제가 되는 상황:
1. **업무 보고서**
   - 진행 상황을 이모지로 표시하는 현대적 문서 작성 방식이 무용지물
   - 업무 상태를 한눈에 파악하기 어려워짐

2. **프로젝트 관리 문서**
   - 단계별, 상태별 구분이 어려워져 관리 효율성 저하
   - 시각적 인덱싱 기능 상실

3. **회의록 및 안건 정리**
   - 중요도나 카테고리 구분이 불가능해져 정보 전달력 감소
   - 참석자들의 문서 이해도 저하

4. **일정 관리 문서**
   - 일정이나 마감일 등의 시간 관련 정보 구분 어려움
   - 긴급도 표시 기능 상실

### 예상되는 원인:
1. **폰트 지원 문제**
   - HWPML 템플릿에서 이모지를 지원하는 폰트가 설정되지 않음
   - 기본 폰트가 이모지 문자를 지원하지 않음

2. **문자 인코딩 문제**
   - UTF-8 이모지가 한글 문서 변환 과정에서 올바르게 처리되지 않음
   - 유니코드 이모지 범위가 제대로 매핑되지 않음

3. **HWPML 변환 엔진 한계**
   - 이모지와 같은 특수 유니코드 문자 처리 기능 부재
   - 마크다운 파서에서 이모지를 일반 텍스트로만 인식

4. **템플릿 설정 문제**
   - 모든 템플릿에서 이모지 표시를 위한 스타일이나 폰트 정의 누락
   - 대체 문자 설정 부재

### 심각도:
- 🐛 중간 (Medium)
- 🎨 시각적 오류
- 변환은 성공하고 내용도 보존되지만 현대적 문서의 핵심 요소인 이모지 표시 실패
- 문서의 시각적 완성도와 직관성이 크게 저하됨
- 모든 템플릿에서 동일한 문제가 발생하여 대체 방안 없음
- 현대적인 업무 문서 작성 트렌드에 맞지 않는 결과물 생성
- 수동으로 한글 문서에서 이모지를 다시 입력하거나 기호로 대체하여 부분적 해결 가능

### 해결 방안 제안:
1. **폰트 지원 개선**
   - 이모지를 지원하는 폰트를 HWPML 템플릿에 추가 설정
   - 예: Segoe UI Emoji, Apple Color Emoji 등

2. **문자 인코딩 강화**
   - UTF-8 이모지 처리 로직 개선
   - 유니코드 이모지 범위에 대한 특별 처리 추가

3. **대체 텍스트 기능**
   - 이모지가 표시되지 않을 경우 의미를 나타내는 텍스트로 자동 변환
   - 예: ✅ → [완료], ⚠️ → [주의] 등

4. **사용자 선택 옵션**
   - 이모지 처리 방식을 사용자가 선택할 수 있는 옵션 제공
   - "이모지 유지", "텍스트 변환", "제거" 등의 선택지

5. **템플릿별 이모지 설정**
   - 각 템플릿에서 이모지 표시 방식을 개별적으로 설정 가능하도록 개선
