# 버그 리포트

## 어떤 버그인가요?

> **제미나이(Gemini) AI**로 생성된 **공공정책 문서**에 포함된 **복잡한 5열 구조의 정책 표**가 **아예 반영되지 않아** **AI별 호환성 문제**가 발생하는 심각한 버그입니다. **ChatGPT는 정상 처리**되지만 **Gemini 생성 문서는 표 변환 실패**로 **AI 생태계 확산**에 따른 **새로운 도전과제**입니다. **공공기관에서 다양한 AI 도구 활용 증가**로 **모든 AI 생성 문서의 안정적 처리**가 필요합니다.

## 실제로 뭐가 잘못되었나요?

### 🚨 **버그 확인 결과**
- **복잡한 정책 표**: ❌ **아예 반영되지 않음**
- **기타 마크다운 요소**: ✅ 제목, 목록, 텍스트 정상 처리
- **AI 호환성**: **ChatGPT는 정상**, **Gemini는 문제 발생**

### 📊 **문제가 되는 표 구조**
```markdown
| 추진 전략 | 세부 사업 예시 | 기대 효과 | 주요 대상 | 참고 지표/사례 |
| :-------- | :------------- | :-------- | :-------- | :------------- |
| **1. 스마트 공원 조성** | 智慧형 공원 관리 시스템 도입 (CCTV, 비상벨, Wi-Fi, IoT 기반 시설물 관리) | 안전성 강화, 관리 효율 증대, 이용 편의성 향상 | 모든 이용객 | 서울특별시 '스마트 서울맵', 국내외 스마트시티 공원 사례 |
```

### 🔍 **표 셀 내용의 복잡성**
1. **매우 긴 텍스트**: 각 셀에 100자 이상의 긴 설명
2. **복잡한 문장 구조**: 괄호, 쉼표, 콜론 등 다양한 구두점
3. **특수 문자**: 한자(智慧), 특수기호(·), 영문 약어
4. **다중 행 내용**: 일부 셀에 여러 줄의 내용

### 🤖 **AI별 차이점**
1. **ChatGPT 생성 문서**: 
   - ✅ 단순하고 명확한 표 구조
   - ✅ 적당한 길이의 셀 내용
   - ✅ 마크다운 표준 준수

2. **Gemini 생성 문서**: 
   - ❌ 매우 복잡하고 긴 표 구조
   - ❌ 과도하게 긴 셀 내용
   - ❌ 마크다운 파서 처리 한계 초과

## 원래는 어떻게 되어야 하나요?

### ✅ **기대되는 정상 동작**
1. **5열 구조의 복잡한 표**: 정상적으로 HWP 문서에 표로 변환
2. **긴 텍스트 셀 내용**: 적절한 줄바꿈과 함께 표시
3. **특수 문자 및 기호**: 원본 그대로 보존
4. **AI 생성 방식 무관**: ChatGPT, Gemini 구분 없이 동일한 품질

### 🎯 **AI 호환성 보장**
- **모든 AI 생성 문서**: 안정적 변환 처리
- **복잡한 구조**: 표 크기나 내용 길이에 관계없이 처리
- **공공기관 업무**: 다양한 AI 도구 활용 지원
