# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서의 이모티콘이 템플릿에 따라 다르게 변환되는 현상이 발생합니다. 대부분의 템플릿에서는 흑백으로 변환되지만, 템플릿문서1.hml에서는 완전히 깨져서 네모 문자(□)로 출력됩니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 손 씻기 방법 안내문
3. 사용했던 템플릿: 
   - template_ex_01.hml (흑백 변환)
   - template_ex_02.hml (흑백 변환)
   - template_ex_03.hml (흑백 변환)
   - 새템플릿.hml (흑백 변환)
   - 템플릿문서.hml (흑백 변환)
   - 템플릿문서1.hml (네모 문자로 깨짐)

테스트한 마크다운 텍스트:
```markdown
# 손 씻기 방법

1. **물로 손을 적신다**  
   - 흐르는 물(🚰)을 틀어 손 전체를 적십시오.

2. **비누를 충분히 묻힌다**  
   - 거품이 잘 나도록 손바닥에 비누(🧼)를 펌핑합니다.

[중략]

```text
# 코드 블럭 내 특수문자 예시

! @ # $ % ^ & * ( ) _ + - = [ ] { } | \ : ; ' " , . < > / ? ~
🚰 🧼 👏 ⏲️
```
```

<br><br>

## 어떤 과정에서 버그가 발생하였나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - template_ex_01~03.hml, 새템플릿.hml, 템플릿문서.hml:
     * 컬러 이모티콘이 흑백으로 변환됨
     * 유사한 모양의 대체 이모티콘으로 변환됨
   - 템플릿문서1.hml:
     * 모든 이모티콘이 네모 문자(□)로 깨져서 출력됨
     * 원본 이모티콘의 의미 완전 손실

### 예상되는 원인:
1. 템플릿별 문자 인코딩 설정 차이
2. 템플릿별 기본 글꼴의 유니코드 지원 범위 차이
3. HWPML 변환 시 이모티콘 처리 로직의 일관성 부재
4. 템플릿문서1.hml의 경우 이모티콘 폰트 미설정 또는 미지원
