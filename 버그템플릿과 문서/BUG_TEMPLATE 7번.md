# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에서 헤더(#)를 제외한 모든 인용구(>) 블록이 한글 문서 변환 시 완전히 누락되는 현상이 발생합니다. 특히 인용구 내부의 서식(굵게, 기울임, 취소선)도 함께 무시됩니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 미국 여행 가이드 문서
3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
# 미국 여행 가이드

> **"미국은 **광활한 대자연**과 **다채로운 도시 문화**가 공존하는 나라입니다."**  
> 
> *"동부 해안부터 서부 해안까지, 각 지역마다 **고유한 매력**이 있습니다."*  
> 
> > **"뉴욕에서 시작해 보세요:**  
> > - **자유의 여신상** (Statue of Liberty) 방문  
> > - *브로드웨이 뮤지컬* 관람  
> > - ~~혼잡하지만~~ **times square** 야경 감상"**  

## 1. 동부 해안 (East Coast)

> **"보스턴(Boston)"**  
> > *"미국 독립 역사의 중심지로, **자유의 길(Freedom Trail)**을 따라가면 주요 유적지를 만날 수 있습니다."*
[이하 생략]
```

<br><br>

## 어떤 과정에서 버그가 발생하였나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 프로그램을 통해 한글 문서로 변환
3. 변환 결과 확인:
   - 헤더(#, ##)로 시작하는 부분만 정상 변환됨
   - 모든 인용구(>) 블록이 완전히 누락됨
   - 인용구 내부의 서식(**, *, ~~)도 모두 무시됨

### 예상되는 원인:
1. 마크다운 파서가 인용구 블록을 인식하지 못함
2. 인용구와 일반 텍스트를 구분하는 로직 오류
3. 인용구 내부의 중첩된 서식 처리 로직 부재
4. HWPML 변환 시 인용구 관련 태그 누락
