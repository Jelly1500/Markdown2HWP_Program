# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에 **HTML 설명 목록(description list) 태그**인 `<dl>`, `<dt>`, `<dd>`가 포함되어 있을 때, 해당 부분이 **완전히 무시되어 변환되지 않는** 치명적인 문제입니다. **용어와 그 설명을 체계적으로 정리**하는 설명 목록 구조가 **통째로 사라져** 문서의 **핵심 내용이 완전히 소실**됩니다. 이는 **행정 용어 해설, 법령 해설, 기술 용어집, 매뉴얼의 용어 정의** 등에서 필수적으로 사용되는 구조로, 이러한 **전문 문서의 가장 중요한 부분이 변환되지 않아** 문서 자체가 **무의미**해지는 심각한 결함입니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 2025년 개정 주요 행정 용어 해설
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
# 2025년 개정 주요 행정 용어 해설

본 자료는 최근 개정되거나 사용 빈도가 높아진 주요 행정 용어에 대한 이해를 돕기 위해 제작되었습니다.

<dl>
  <dt>적극행정 (積極行政)</dt>
  <dd>공무원이 공공의 이익을 위하여 창의성과 전문성을 바탕으로 적극적으로 업무를 처리하는 행위. 관행에 얽매이지 않고 새로운 방식으로 문제를 해결하려는 노력을 포함합니다.</dd>
  <dd>관련 사례는 <a href="https://www.mpm.go.kr/ 적극행정온" target="_blank" title="인사혁신처 적극행정온 페이지로 이동">인사혁신처 적극행정온</a>에서 확인할 수 있습니다.</dd>

  <dt>데이터 기반 행정</dt>
  <dd>객관적인 데이터와 과학적 분석 결과를 정책 결정 및 행정 서비스 개선에 활용하는 행정 방식입니다. <u>증거 기반 정책 결정</u>을 지향합니다.</dd>
  <dd>주요 활용 기술:
    <ul>
      <li>빅데이터 분석</li>
      <li>인공지능(AI) 예측 모델</li>
      <li>시각화 도구 (BI 툴 등)</li>
    </ul>
  </dd>

  <dt>디지털플랫폼정부 (DPG: Digital Platform Government)</dt>
  <dd>모든 데이터가 연결되는 '디지털 플랫폼' 위에서 국민, 기업, 정부가 함께 사회문제를 해결하고 새로운 가치를 창출하는 정부를 의미합니다. <em>국민 맞춤형 서비스 제공</em>이 핵심 목표 중 하나입니다.</dd>
  <dd>추진 과제로는 <code>공공데이터 개방 확대</code>, <code>마이데이터 도입</code>, <code>클라우드 전환</code> 등이 있습니다.</dd>

  <dt>ESG (Environmental, Social, and Governance)</dt>
  <dd>환경(Environment), 사회(Social), 지배구조(Governance)의 약자로, 기업이나 조직의 지속 가능한 성장을 위한 비재무적 성과 지표입니다. 공공 부문에서도 점차 중요성이 강조되고 있습니다.</dd>
    <dd>특히, <del>기존의 단기적 성과 중심에서 벗어나</del> <strong>장기적 관점의 사회적 책임 이행</strong>이 요구됩니다.</dd>

  <dt>메타버스 (Metaverse)</dt>
  <dt>확장현실 (XR: Extended Reality)</dt>
  <dd>가상현실(VR), 증강현실(AR), 혼합현실(MR) 등을 아우르는 초실감형 기술 및 그 기술이 구현하는 가상 세계를 통칭합니다. 공공 서비스 제공 및 정책 시뮬레이션 등에 활용될 가능성이 연구되고 있습니다.</dd>
  <dd>예시: <span>가상현실 기반 안전체험관</span>, <span>도시계획 시뮬레이션</span> 등</dd>
</dl>

본 용어 해설은 관련 법규 및 지침 개정에 따라 지속적으로 업데이트될 예정입니다.
```

<br><br>

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 시도
3. 변환 결과 확인:
   - **모든 템플릿에서 동일한 치명적 오류 발생:**
     * **HTML 설명 목록 전체가 완전히 무시됨**
     * **5개 주요 용어의 모든 해설 내용이 사라짐**
     * **문서의 핵심 내용이 통째로 소실됨**
     * **제목과 앞뒤 설명문만 남고 실질 내용 전무**

### 구체적인 문제 상황:
1. **기대되는 결과:**
   - **적극행정**: 정의와 관련 사례 링크가 포함된 상세 설명
   - **데이터 기반 행정**: 정의와 주요 활용 기술 목록
   - **디지털플랫폼정부**: 정의와 추진 과제 설명
   - **ESG**: 정의와 공공 부문 적용 내용
   - **메타버스/확장현실**: 정의와 공공 활용 예시
   - **각 용어가 명확히 구분**되어 **체계적인 용어집** 형태로 표시

2. **실제 발생하는 결과:**
   ```
   2025년 개정 주요 행정 용어 해설

   본 자료는 최근 개정되거나 사용 빈도가 높아진 주요 행정 용어에 대한 이해를 돕기 위해 제작되었습니다.

   본 용어 해설은 관련 법규 및 지침 개정에 따라 지속적으로 업데이트될 예정입니다.
   ```
   - **모든 용어 해설 내용이 완전히 사라짐**
   - **문서 제목과 머리말, 맺음말만 남음**
   - **핵심 내용 100% 소실**로 **문서가 무의미**해짐

### 완전히 무시되는 HTML 설명 목록 구조:
1. **기본 설명 목록 태그**
   ```html
   <dl>                <!-- description list -->
   <dt>용어</dt>        <!-- description term -->
   <dd>설명</dd>        <!-- description definition -->
   </dl>
   ```

2. **복수 설명이 있는 용어**
   ```html
   <dt>적극행정</dt>
   <dd>첫 번째 설명...</dd>
   <dd>두 번째 설명 (관련 사례)...</dd>
   ```

3. **HTML 태그가 중첩된 설명**
   ```html
   <dd>주요 활용 기술:
     <ul>
       <li>빅데이터 분석</li>
       <li>인공지능(AI) 예측 모델</li>
     </ul>
   </dd>
   ```

4. **다양한 인라인 HTML 태그 포함**
   ```html
   <dd><u>증거 기반 정책 결정</u>을 지향합니다.</dd>
   <dd><em>국민 맞춤형 서비스 제공</em>이 핵심 목표...</dd>
   <dd><code>공공데이터 개방 확대</code>, <code>마이데이터 도입</code>...</dd>
   <dd><del>기존의 단기적 성과 중심에서 벗어나</del> <strong>장기적 관점...</strong></dd>
   ```

5. **하나의 설명에 여러 용어 연결**
   ```html
   <dt>메타버스 (Metaverse)</dt>
   <dt>확장현실 (XR: Extended Reality)</dt>
   <dd>가상현실(VR), 증강현실(AR), 혼합현실(MR) 등을 아우르는...</dd>
   ```

### 특히 문제가 되는 상황:
1. **행정 용어 해설집**
   - **공무원 교육**이나 **시민 대상 안내**에서 필수적인 문서 유형
   - **용어와 정의가 체계적으로 정리**되어야 하는 전문 문서
   - **핵심 내용 소실**로 **교육 자료로서 완전히 무의미**해짐

2. **법령 및 규정 해설**
   - **법적 용어**나 **행정 절차**를 **일반인도 이해할 수 있게** 설명하는 문서
   - **정확한 정의**와 **구체적 설명**이 **법적 효력**과 직결
   - **해설 부분 소실**로 **법적 안내 기능 완전 상실**

3. **기술 용어집 및 매뉴얼**
   - **디지털 정부**, **정보 시스템** 관련 **전문 용어 설명**
   - **업무 담당자 간 소통**과 **시민 서비스 설명**에 필수
   - **용어 정의 부재**로 **업무 혼란**과 **서비스 품질 저하**

4. **정책 설명 자료**
   - **새로운 정책**이나 **제도 도입** 시 **핵심 개념 설명**
   - **언론 브리핑**, **시민 설명회** 등에서 **참고 자료**로 활용
   - **설명 내용 소실**로 **정책 홍보 및 소통 기능 마비**

### 예상되는 원인:
1. **HTML 설명 목록 태그 파싱 부재**
   - 마크다운 파서에서 **`<dl>`, `<dt>`, `<dd>` 태그를 인식하지 못함**
   - **일반적인 HTML 태그와 달리** 설명 목록 구조에 대한 **특별한 처리 로직 없음**
   - **블록 레벨 HTML 태그**에 대한 **전반적인 지원 부족**

2. **HWPML 설명 목록 매핑 기능 부재**
   - 한글 문서에는 **설명 목록에 해당하는 서식**이 존재하지만 **매핑 로직 없음**
   - **용어-설명 구조**를 **한글 문서 형식으로 변환**하는 기능 부재
   - **들여쓰기나 번호 없는 목록** 등으로 **대체 표현**하는 방안도 없음

3. **복합 HTML 구조 처리 한계**
   - **설명 목록 내부의 다른 HTML 태그들** (`<ul>`, `<li>`, `<code>`, `<em>` 등) **중첩 처리 실패**
   - **블록 레벨과 인라인 레벨 태그가 혼재**된 복잡한 구조 **파싱 불가**
   - **HTML 태그 간 의존 관계**를 **이해하지 못하는** 단순 파싱

4. **마크다운-HTML 혼합 문서 지원 한계**
   - **순수 마크다운 문법 외**의 **HTML 확장 기능**에 대한 **근본적 지원 부족**
   - **CommonMark 표준**에서 **허용하는 HTML 태그 사용**이 **실제로 구현되지 않음**
   - **웹 표준 HTML 태그**와 **한글 문서 서식** 간 **변환 체계 부재**

### 심각도:
- 🐛 심각 (Critical)
- 📝 서식 미지원
- **절대 최고 심각도** - 문서 핵심 내용 100% 소실
- **용어 해설, 법령 해설, 기술 문서**의 **가장 중요한 부분 완전 무시**
- **전문 문서의 실질적 가치 완전 상실**
- **교육 자료, 참고 자료로서 기능 완전 마비**
- 모든 템플릿에서 동일한 문제로 **대체 방안 전혀 없음**
- **공공기관의 용어 해설, 정책 설명 기능 원천 차단**
- **시민 대상 정보 제공 서비스 심각 훼손**

### 임시 해결 방안:
1. **마크다운 목록으로 대체**
   - HTML 설명 목록 대신 **마크다운 문법 사용**
   ```markdown
   ## 적극행정 (積極行政)
   공무원이 공공의 이익을 위하여...
   
   관련 사례는 [인사혁신처 적극행정온]에서...
   ```
   - **용어-설명 구조**는 유지되지만 **시각적 구분 효과 상실**

2. **제목과 본문으로 분리**
   - 각 용어를 **개별 제목(## 또는 ###)**으로 처리
   - 설명을 **일반 문단**으로 작성
   - **용어집의 간결함**은 사라지지만 **내용은 보존**

3. **테이블 형식으로 변환**
   ```markdown
   | 용어 | 설명 |
   |------|------|
   | 적극행정 | 공무원이 공공의 이익을 위하여... |
   ```
   - **체계적 정리** 효과는 있지만 **복잡한 설명에는 부적합**

4. **번호 없는 목록 활용**
   ```markdown
   - **적극행정**: 공무원이 공공의 이익을 위하여...
   - **데이터 기반 행정**: 객관적인 데이터와...
   ```
   - **간단한 용어 정리**에는 적합하지만 **상세 설명에는 한계**

### 근본적 해결 방안 제안:
1. **HTML 설명 목록 완전 지원**
   - **`<dl>`, `<dt>`, `<dd>` 태그**를 **정확히 인식하고 파싱**하는 기능 구현
   - **중첩된 HTML 구조**도 **안정적으로 처리**하는 고급 파서 개발
   - **웹 표준 HTML 태그 지원 확대**

2. **HWPML 설명 목록 서식 매핑**
   - 한글 문서의 **들여쓰기, 번호 없는 목록** 등을 활용한 **설명 목록 표현**
   - **용어는 굵게**, **설명은 들여쓰기** 등의 **시각적 구분** 구현
   - **전문적이고 체계적인 용어집** 서식 제공

3. **용어집 전용 변환 모드**
   - **설명 목록이 포함된 문서**를 **자동 감지**하는 기능
   - **용어집, 해설서, 매뉴얼** 등에 **특화된 변환 옵션** 제공
   - **용어-설명 구조**를 **최적화된 형태**로 변환

4. **HTML-마크다운 하이브리드 지원 강화**
   - **마크다운의 단순함**과 **HTML의 표현력**을 **모두 지원**하는 파서
   - **CommonMark 표준 완전 준수** 및 **확장 HTML 태그 지원**
   - **웹 문서 작성 표준**과 **한글 문서 서식** 간 **완벽한 브리지** 구현
