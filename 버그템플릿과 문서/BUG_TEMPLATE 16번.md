# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에서 밑줄(<u>)과 취소선(~~) 서식이 적용된 텍스트가 한글 문서로 변환될 때 일반 텍스트로 변환되는 현상이 발생합니다. 이는 문서의 강조 표현과 수정 내역을 표시하는데 중요한 서식이 손실되는 문제입니다. 

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 2025년 상반기 주요 정책 성과 및 보완점 보고서 (초안)
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
### 가. 스마트 민원 시스템 확대
- **성과:** 민원 처리 평균 소요 시간 <u>15% 단축</u> 및 사용자 만족도 ~~85점~~ <u>90점 달성</u>.
- **보완점:** ~~모바일 앱 접근성 개선 필요~~ (<u>차세대 시스템에서 전면 개편 예정</u>).

### 나. 친환경 도시 조성 사업
- **성과:** 도심 녹지 면적 <u>5% 확대</u>, ~~미세먼지 농도 소폭 감소~~.
- **보완점:** <u>~~자전거 도로 추가 확보 시급~~</u> (예산 문제로 보류, <u>대체 경로 발굴 중</u>).
```

<br><br>

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - 모든 템플릿에서 동일한 문제 발생:
     * 밑줄(<u>) 서식이 완전히 무시됨
     * 취소선(~~) 서식이 완전히 무시됨
     * 예시:
       ```
       원본: 민원 처리 평균 소요 시간 <u>15% 단축</u> 및 사용자 만족도 ~~85점~~ <u>90점 달성</u>
       변환: 민원 처리 평균 소요 시간 15% 단축 및 사용자 만족도 85점 90점 달성
       ```
     * 서식이 적용된 모든 텍스트가 일반 텍스트로 변환됨
   - 문서의 강조 표현이 사라짐
   - 수정 내역 추적이 불가능해짐

### 예상되는 원인:
1. 마크다운 파서가 밑줄(<u>)과 취소선(~~) 태그를 인식하지 못함
2. HWPML 변환 시 해당 서식에 대한 매핑 규칙 부재
3. 서식 변환 처리 로직에서 밑줄과 취소선 처리 누락
4. HTML 중간 변환 과정에서 해당 태그 처리 미구현
5. 한글 문서의 서식 스타일 정의에 해당 서식 누락
