# 버그 리포트

## 어떤 버그인가요?

> ChatGPT에 중첩된 인용구(>) 생성을 요청할 때, 시각적으로는 중첩된 형태로 보여주지만 실제 복사-붙여넣기 시에는 모든 텍스트가 인용구 기호 없이 출력되는 현상이 발생합니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: ChatGPT로 생성한 중첩 인용구 테스트
3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

ChatGPT 응답 (시각적으로 보이는 형태):
```text
[들여쓰기된 형태로 보임]
  "페이커(이상혁)는 e스포츠 역사상 가장 성공적인 리그 오브 레전드 선수로 평가받는다.
    "2013년 SK텔레콤 T1에 입단한 이후, 그는 놀라운 기량으로 단숨에 주목을 받았다.
      "데뷔 시즌부터 미드 라인에서 독보적인 플레이를 선보이며...
```

실제 복사-붙여넣기 결과:
```text
"페이커(이상혁)는 e스포츠 역사상 가장 성공적인 리그 오브 레전드 선수로 평가받는다.

"2013년 SK텔레콤 T1에 입단한 이후, 그는 놀라운 기량으로 단숨에 주목을 받았다.

"데뷔 시즌부터 미드 라인에서 독보적인 플레이를 선보이며, 초창기부터 'GOAT(역대 최고)'라는 별명을 얻게 되었다."
```

<br><br>

## 어떤 과정에서 버그가 발생하였나요?

1. ChatGPT에 중첩된 인용구 구조의 텍스트 생성 요청
2. ChatGPT의 응답 확인:
   - 화면상: 들여쓰기된 형태로 보임
   - 복사 결과: '>' 기호 없이 일반 텍스트로만 출력

### 예상되는 원인:
1. ChatGPT의 마크다운 렌더링과 실제 텍스트 출력 방식의 차이
2. 시각적 표현과 실제 마크다운 문법 간의 불일치

<br><br>

## 환경
- OS: Windows 10
- 프로그램 버전: v1.0.0

## 설명
마크다운의 중첩된 인용구(Nested Blockquotes)가 한글 문서로 변환 시 올바르게 처리되지 않는 문제가 있습니다.

## 재현 방법
1. 아래의 마크다운 텍스트를 입력합니다:

```markdown
> "페이커(이상혁)는 e스포츠 역사상 가장 성공적인 리그 오브 레전드 선수로 평가받는다.  
> 
> > "2013년 SK텔레콤 T1에 입단한 이후, 그는 놀라운 기량으로 단숨에 주목을 받았다.  
> > 
> > > "데뷔 시즌부터 미드 라인에서 독보적인 플레이를 선보이며, 초창기부터 'GOAT(역대 최고)'라는 별명을 얻게 되었다.  
> > > 
> > > > "2013, 2015, 2016 월드 챔피언십 우승을 이끌었고, SK텔레콤 T1을 리그 오브 레전드의 전설로 만들었다.  
> > > 
> > > "그가 사용하는 라이즈, 르블랑, 아지르는 전설적인 명승부를 수없이 만들어냈다.  
> > > 
> > "페이커의 영향력은 단지 경기 기록에만 국한되지 않는다.  
> > 
> > > "팀원들에게 안정감을 주는 리더십과, 전 세계 팬들에게 영감을 주는 프로 정신은 그의 진정한 가치를 보여준다.  
> > 
> > "지금도 그는 매 경기 최선을 다하며, 새로운 세대에게 롤모델이 되고 있다."  
> 
> "이상혁, 바로 '페이커'다."
```

2. 프로그램을 실행하여 한글 문서로 변환합니다.

## 기대 동작
- 각 인용구 레벨에 따라 들여쓰기가 순차적으로 적용되어야 함
- 인용구 내의 텍스트 서식이 유지되어야 함
- 각 인용구 단계마다 시각적 구분이 명확해야 함

## 실제 동작
- 모든 인용구가 동일한 레벨로 변환됨
- 중첩된 인용구의 계층 구조가 사라짐
- 인용구 내의 서식이 제대로 적용되지 않음

## 심각도
높음 (High)

## 우선순위
높음 (High)

## 영향
- 중첩된 인용구를 사용하는 모든 문서에 영향
- 특히 인터뷰, 대화, 토론 등의 내용을 담은 문서에서 심각한 가독성 저하 발생

## 해결 방안 제안
1. 인용구 파싱 로직 개선
   - 중첩 레벨 감지 및 처리 로직 추가
   - 각 레벨별 적절한 들여쓰기 값 설정

2. 한글 문서 변환 시
   - 각 레벨별 다른 스타일 적용 (들여쓰기 크기, 테두리 스타일 등)
   - 인용구 내부 서식 처리 로직 보완

## 비고
- 현재 6개의 테스트 템플릿 모두에서 동일한 문제 발생 확인
- 인용구의 깊이가 깊어질수록 가독성 문제가 더욱 심각해짐
