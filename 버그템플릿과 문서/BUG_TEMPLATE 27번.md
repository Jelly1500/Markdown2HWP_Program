# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서의 **목록 항목에 HTML 주석**(`<!-- -->`)이 포함되어 있을 때, 주석이 **숨겨지지 않고 일반 텍스트로 그대로 표시**되는 시각적 오류입니다. HTML 주석은 원래 문서 작성자의 메모나 설명을 위한 **보이지 않는 주석**이어야 하지만, 변환된 한글 문서에서는 `<!-- 내용 -->`이 **그대로 텍스트로 노출**되어 문서의 **가독성과 전문성을 심각하게 저해**합니다. 특히 **업무 문서, 매뉴얼, 가이드라인** 등에서 작성자 메모나 추가 설명을 주석으로 넣는 경우가 많은데, 이러한 **내부 정보가 최종 문서에 그대로 노출**되는 것은 문서 품질 관리에 치명적인 문제입니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 봄철 나들이 준비물 리스트
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
# 봄철 나들이 준비물 리스트

아래는 봄나들이를 떠나기 전 챙기면 좋은 준비물 목록입니다.  
목록 사이에는 **주석**으로 추가 설명을 넣었습니다.

1. 반팔 티셔츠  
   <!-- 가벼운 옷차림이지만, 아침저녁으로 쌀쌀할 수 있으니 가디건도 챙기세요. -->
2. 얇은 가디건  
   <!-- 햇볕이 강할 때는 접어 가방에 넣었다가 사용하세요. -->
3. 데님 또는 면바지  
   <!-- 활동하기 편안한 바지로 선택하면, 야외 활동 시 유용합니다. -->
4. 운동화  
   <!-- 오래 걷거나 불규칙한 지형에서도 발을 보호해 줍니다. -->
5. 모자 (챙 넓은)  
   <!-- 강한 햇빛으로부터 얼굴을 보호할 수 있습니다. -->
6. 선크림 (SPF 50 이상 권장)  
   <!-- 자외선 차단 효과가 높은 제품을 사용하면 좋습니다. -->
7. 선글라스  
   <!-- 눈을 보호하고 가벼운 스타일링 아이템이 됩니다. -->
8. 물병 (500ml 이상)  
   <!-- 충분한 물을 준비해 두면, 갈증 해소에 편리합니다. -->
9. 간단한 간식 (과일, 견과류 등)  
   <!-- 당분 보충이 필요할 때 간편하게 섭취할 수 있습니다. -->
10. 돗자리 또는 휴대용 방석  
    <!-- 앉아서 쉴 공간이 필요할 때 유용합니다. -->
11. 비닐봉투 또는 재사용 가능한 지퍼백  
    <!-- 쓰레기나 젖은 옷을 따로 보관할 때 사용합니다. -->
12. 간이 구급함 (반창고, 소독약 등)  
    <!-- 작은 상처나 긴급 상황에 대비할 수 있습니다. -->

<!-- 
추가 팁: 
- 스마트폰 충전 케이블과 보조 배터리를 함께 챙기세요. 
- 야외 활동 중 비가 올 수도 있으니 우비나 소형 우산을 준비하면 좋습니다.
-->

- **물과 간식을 충분히 섭취**하여 탈수를 예방하세요.  
  <!-- 땀을 많이 흘리는 활동을 할 때, 전해질 보충 음료도 도움이 됩니다. -->
- **햇볕을 피할 수 있는 그늘**이나 그늘막을 준비하면, 더위에 지치는 것을 막을 수 있습니다.  
  <!-- 그늘막은 설치가 간편한 팝업형 제품을 추천합니다. -->
- **휴식 시간을 자주** 갖고, 지나친 활동으로 몸이 지치지 않도록 합니다.  
  <!-- 특히 아이나 노약자와 함께할 경우에는 더욱 주의해야 합니다. -->

끝.
```

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 시도
3. 변환 결과 확인:
   - **모든 템플릿에서 동일한 시각적 오류 발생:**
     * HTML 주석 `<!-- 내용 -->`이 **그대로 일반 텍스트로 표시됨**
     * 목록 항목 아래에 주석 내용이 **일반 문장처럼 노출됨**
     * 문서에 **불필요한 작성자 메모가 모두 공개**됨
     * 전체적인 **문서 가독성과 전문성이 심각하게 저하**됨

### 구체적인 문제 상황:
1. **기대되는 결과:**
   - HTML 주석 `<!-- 가벼운 옷차림이지만, 아침저녁으로 쌀쌀할 수 있으니 가디건도 챙기세요. -->`는 **완전히 숨겨져야 함**
   - 최종 문서에서는 `1. 반팔 티셔츠`만 표시되고 주석은 보이지 않아야 함
   - 작성자의 메모나 추가 설명은 **내부 정보로 유지**되어야 함
   - 깔끔하고 전문적인 **최종 문서만 사용자에게 제공**되어야 함

2. **실제 발생하는 결과:**
   - `1. 반팔 티셔츠`
   - `<!-- 가벼운 옷차림이지만, 아침저녁으로 쌀쌀할 수 있으니 가디건도 챙기세요. -->`
   - 위처럼 주석이 **그대로 텍스트로 표시됨**
   - 작성자의 **내부 메모가 모두 공개**되어 버림
   - 문서가 **미완성된 것처럼 보이고 비전문적**으로 보임
   - **가독성이 심각하게 저하**되어 핵심 내용 파악이 어려움

### 구체적인 시각적 문제들:
1. **목록 항목별 주석 노출**
   - 각 준비물 항목마다 `<!-- 설명 -->` 형태로 주석이 그대로 표시
   - 목록의 깔끔함이 완전히 사라지고 복잡해 보임
   - 필수 항목과 부가 설명이 구분되지 않음

2. **블록 주석의 완전한 노출**
   ```
   <!-- 
   추가 팁: 
   - 스마트폰 충전 케이블과 보조 배터리를 함께 챙기세요. 
   - 야외 활동 중 비가 올 수도 있으니 우비나 소형 우산을 준비하면 좋습니다.
   -->
   ```
   - 위 내용이 **그대로 문서에 표시**됨
   - 주석 표시 기호(`<!--`, `-->`)까지 **일반 텍스트로 노출**
   - 작성자가 **임시로 메모한 내용**이 최종 문서에 포함됨

3. **인라인 주석의 연속 표시**
   - `- **물과 간식을 충분히 섭취**하여 탈수를 예방하세요.`
   - `<!-- 땀을 많이 흘리는 활동을 할 때, 전해질 보충 음료도 도움이 됩니다. -->`
   - 위처럼 본문과 주석이 **연달아 표시**되어 매우 복잡해 보임

### 특히 문제가 되는 상황:
1. **업무 문서 작성**
   - 보고서, 제안서, 계획서 등에서 작성자의 **내부 검토 의견**이 그대로 노출
   - **미완성 문서처럼 보여** 업무 전문성 저하
   - 상급자나 관련 부서에 제출 시 **매우 부적절한 인상** 제공

2. **매뉴얼 및 가이드라인**
   - **작성 과정의 고민이나 메모**가 최종 사용자에게 그대로 전달
   - 사용자 혼란 야기 및 **신뢰도 하락**
   - **완성된 가이드가 아닌 초안**처럼 보이는 문제

3. **교육 자료 및 안내문**
   - 강사나 작성자의 **개인적 메모**가 수강생이나 시민에게 노출
   - **공식 문서의 품격과 완성도** 심각하게 저하
   - 정보 전달의 명확성과 일관성 훼손

4. **공공 문서 및 민원 안내**
   - 담당자의 **업무 처리 과정 메모**가 시민에게 그대로 공개
   - **행정 서비스의 전문성 의심** 받을 수 있음
   - 공공기관의 **문서 관리 역량 문제**로 인식될 가능성

### 예상되는 원인:
1. **HTML 주석 파싱 기능 부재**
   - 마크다운 파서에서 HTML 주석을 **구분하지 못함**
   - `<!--`와 `-->`를 **일반 텍스트 문자**로만 인식
   - HTML 요소와 주석을 **분리 처리하는 로직 없음**

2. **주석 필터링 기능 부재**
   - 변환 과정에서 **주석 제거 단계가 없음**
   - 모든 텍스트를 **동일하게 출력 대상으로 처리**
   - 숨김 처리해야 할 요소에 대한 **구분 기준 부재**

3. **HTML-Markdown 혼합 처리 한계**
   - 마크다운 내 HTML 요소 처리 기능의 **전반적 부족**
   - 특히 **비표시 요소(주석)**에 대한 처리 로직 부재
   - HTML과 마크다운 문법 혼용 시 **예외 처리 부족**

4. **텍스트 전처리 과정 부재**
   - 변환 전 **불필요한 요소 제거** 과정 없음
   - 주석, 메타데이터, 임시 메모 등을 **구분하지 못함**
   - **정제된 텍스트만 추출**하는 기능 부재

### 심각도:
- 🐛 중간 (Moderate)
- 🎨 시각적 오류
- **문서 품질 및 전문성 심각 저하**
- 작성자 의도와 완전히 다른 결과물 생성
- 업무용, 공식 문서 사용 시 **부적절한 인상** 제공
- **내부 정보 노출**로 인한 보안성 문제 우려
- 모든 템플릿에서 동일한 문제로 **대체 방안 없음**
- **현대적 문서 작성 관습**과 동떨어진 결과물
- 마크다운의 **기본적인 HTML 지원 기능** 부재

### 임시 해결 방안:
1. **수동 주석 제거**
   - 변환 전 모든 HTML 주석을 **수동으로 삭제**
   - 정규표현식 `<!--.*?-->`를 사용해 **일괄 제거**
   - 주석 내용이 필요한 경우 **별도 파일로 관리**

2. **텍스트 에디터 활용**
   - Find & Replace 기능으로 `<!--`와 `-->` **일괄 검색 후 수동 제거**
   - VS Code, Notepad++ 등에서 **정규표현식 치환** 활용
   - 변환 전 **전처리 과정**으로 주석 정리

3. **문서 작성 방식 변경**
   - HTML 주석 대신 **마크다운 문법만 사용**
   - 임시 메모는 **별도 파일**이나 **문서 최하단**에 기록
   - **최종 검토 시 모든 메모 제거** 후 변환

### 근본적 해결 방안 제안:
1. **HTML 주석 필터링 기능 추가**
   - 변환 과정에서 `<!--.*?-->` 패턴을 **자동으로 제거**하는 기능
   - 사용자 옵션으로 **주석 포함/제외 선택** 가능하게 구현
   - **다단계 주석 중첩**도 올바르게 처리하는 고급 파싱

2. **HTML 요소 분류 시스템**
   - **표시 요소**와 **비표시 요소**를 구분하는 분류 체계
   - 주석, 메타태그, 스크립트 등을 **비표시 요소**로 분류
   - **표시 요소만 선별적으로 변환**하는 필터 시스템

3. **전처리 옵션 제공**
   - 변환 전 **텍스트 정제 옵션** 제공
   - "주석 제거", "메타데이터 제거", "임시 텍스트 제거" 등
   - 사용자가 **문서 정제 수준을 선택**할 수 있는 UI

4. **프리뷰 기능 개선**
   - 변환 전 **최종 결과물 미리보기** 제공
   - 주석이 포함될지 여부를 **사전에 확인**할 수 있는 기능
   - **문제가 되는 요소들을 하이라이트**로 표시하는 검토 도구
