# 버그 리포트

## 어떤 버그인가요?

> **사하구청 걷기 대회 안내**와 같은 **실제 공공기관 안내문**에서 **수평선 구분자(`---`)가 표시되지 않고 끊김 현상**이 발생하여 **문서의 시각적 구분 효과가 상실**되는 버그입니다. **주민 대상 안내문**, **각종 행사 및 사업 안내**, **민원 처리 절차 안내** 등에서 **섹션 구분이 불명확**해져 **내용 파악이 어려워지고** **공식 문서의 체계적 형식이 미준수**되어 **정부 문서의 전문성이 훼손**됩니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. **실행 환경**: Windows 10, Python 가상환경  
2. **테스트 문서**: 사하구청 제2회 구민 건강 걷기 대회 안내 (AI 생성 랜덤 공공문서)  
3. **테스트한 템플릿**:  
   - template_ex_01.hml ❌ 수평선 구분자 표시되지 않음  
   - template_ex_02.hml ❌ 수평선 구분자 표시되지 않음  
   - template_ex_03.hml ❌ 수평선 구분자 표시되지 않음  
   - 새템플릿.hml ❌ 수평선 구분자 표시되지 않음  
   - 템플릿문서.hml ❌ 수평선 구분자 표시되지 않음  
   - 템플릿문서1.hml ❌ 수평선 구분자 표시되지 않음  

<br><br>

## 실제로 뭐가 잘못되었나요?

### ✅ **정상 처리되는 요소들**
1. **기본 마크다운 구조**: 헤더 계층 구조 (# ## ###)
2. **목록 처리**: 순서있는/없는 목록, 중첩 목록 구조
3. **텍스트 서식**: **굵게**, _기울임_, 링크 및 이메일 주소
4. **표(테이블) 처리**: 행사 일정표, 시상 내역표 정상 렌더링
5. **전체 평가**: **"그외는 좋음"** - 수평선 제외하고는 완벽

### ❌ **문제가 되는 요소**
1. **수평선 구분자 (---) 렌더링 실패**
   ```markdown
   ---
   ```
   - 문서 전체에 **7개의 수평선** 사용
   - 모든 수평선이 렌더링되지 않음
   - **"끊김 현상"** 발생으로 시각적 구분 효과 상실

### 📍 **수평선 사용 목적 및 위치**
1. **헤더 아래 구분선**: 제목과 본문 구분
2. **섹션 간 구분선**: 각 챕터 간 명확한 구분
3. **마지막 서명란 구분**: 공식 문서의 마감 표시

<br><br>

## 원래는 어떻게 되어야 하나요?

### ✅ **기대되는 정상 동작**
1. **수평선 표시**: `---` 마크다운 문법이 시각적 구분선으로 렌더링
2. **섹션 구분 효과**: 각 섹션 간 명확한 시각적 분리
3. **공식 문서 형식**: 정부 문서의 체계적 구성 요소 완전 지원
4. **HTML HR 태그 대안**: `<hr>` 태그 지원으로 우회 방법 제공

### 🎯 **공공기관 업무 필수 요구사항**
- **시각적 가독성**: 긴 문서의 섹션 구분 필수
- **공식성 표현**: 정부 문서의 체계적 구성 요소
- **정보 전달 효과**: 내용 단위별 명확한 분리

### 🏢 **공공기관 업무 영향도**
1. **실제 사용되는 문서 유형**
   - **주민 대상 안내문**: 각종 행사 및 사업 안내, 민원 처리 절차 안내, 정책 변경 사항 공지
   - **내부 업무 문서**: 회의록 및 보고서, 업무 지침 및 매뉴얼, 부서 간 협조 요청서
   - **대외 협력 문서**: 유관기관 협조 공문, 사업 제안서 및 계획서, 예산 신청 및 정산 보고서

2. **수평선 미지원으로 인한 문제**
   - **가독성 저하**: 섹션 구분이 불명확해져 내용 파악 어려움, 긴 문서에서 현재 위치 파악 곤란
   - **공식성 훼손**: 정부 문서의 체계적 형식 미준수, 수신자에게 비전문적 인상 제공
   - **정보 전달 효과 감소**: 중요 내용과 일반 내용의 구분 모호, 단계별 절차나 일정의 시각적 구분 실패

### 💡 **즉시 해결 방안**
1. **HTML HR 태그 지원**
   ```html
   <hr>
   ```
   - 수평선 마크다운 대신 HTML 태그 지원

2. **CSS 스타일링 추가**
   ```css
   hr {
       border: none;
       border-top: 1px solid #ccc;
       margin: 1em 0;
   }
   ```

3. **마크다운 파서 개선**
   - `---` 패턴 인식 및 HR 태그 변환 로직 추가
