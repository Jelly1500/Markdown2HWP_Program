# 버그 리포트

## 어떤 버그인가요?

> **마크다운 테이블의 셀 내부에 HTML 테이블이 중첩**되어 있을 때, **중첩된 HTML 테이블 부분이 완전히 무시**되어 변환되지 않는 심각한 문제입니다. **복잡한 데이터 구조나 세부 정보를 체계적으로 표현**하기 위해 사용되는 **중첩 테이블 구조**가 **통째로 사라져** 문서의 **핵심 상세 내용이 완전히 소실**됩니다. 이는 **교육 과정 커리큘럼, 프로젝트 세부 계획, 제품 사양서, 업무 매뉴얼** 등에서 **복합적인 정보를 구조화**할 때 필수적으로 사용되는 패턴으로, 이러한 **전문 문서의 가장 중요한 세부 정보가 변환되지 않아** 문서의 **실질적 가치가 심각하게 훼손**되는 치명적 결함입니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 교육 과정 및 커리큘럼
3. 테스트한 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 시도
3. 변환 결과 확인:
   - **모든 템플릿에서 동일한 심각한 오류 발생:**
     * **중첩된 HTML 테이블 전체가 완전히 무시됨**
     * **교육 과정의 상세한 모듈별 커리큘럼 정보가 모두 사라짐**
     * **과정 이름과 간단한 설명만 남고 핵심 세부 내용 전무**
     * **복잡한 데이터 구조의 가장 중요한 부분 완전 소실**

### 구체적인 문제 상황:
1. **기대되는 결과:**
   - **웹 개발 과정**: 
     * HTML/CSS (2주) - 웹 페이지 레이아웃 및 스타일링 기초
     * JavaScript (3주) - 동적 콘텐츠 생성 및 DOM 조작
     * 프론트엔드 프레임워크(React) (3주) - 컴포넌트 기반 UI 설계 및 상태 관리
     * 백엔드(Node.js/Express) (4주) - RESTful API 설계 및 데이터베이스 연동
   - **데이터 과학 과정**:
     * Python 기초 (2주) - Python 문법 및 데이터 구조 이해
     * 데이터 전처리(Pandas) (3주) - 결측치 처리, 정렬, 그룹화 등 핵심 기능
     * 데이터 시각화(Matplotlib/Seaborn) (2주) - 차트 및 그래프 생성, 시각적 인사이트 도출
     * 머신러닝 기초(sklearn) (4주) - 지도/비지도 학습 알고리즘 활용
     * 프로젝트 실습 (3주) - 실제 데이터셋을 활용한 모델링 및 배포
   - **각 모듈의 기간과 세부 설명이 체계적으로 정리**된 완전한 커리큘럼 테이블

2. **실제 발생하는 결과:**
   ```
   | 과정        | 설명                        | 세부 커리큘럼 |
   |-------------|----------------------------|---------------|
   | 웹 개발     | 웹 애플리케이션 개발의 기초 | (빈 공간)     |
   | 데이터 과학 | 데이터 처리 및 분석         | (빈 공간)     |
   ```
   - **모든 세부 커리큘럼 내용이 완전히 사라짐**
   - **교육 과정의 핵심 정보인 모듈별 내용과 기간 정보 전무**
   - **테이블 구조는 유지되지만 가장 중요한 세부 정보 100% 소실**

### 완전히 무시되는 중첩 HTML 테이블 구조:
1. **마크다운 테이블 내 HTML 테이블 중첩**
   ```markdown
   | 컬럼1 | 컬럼2 | 중첩 테이블 컬럼 |
   |-------|-------|-----------------|
   | 값1   | 값2   | <table><tr><th>내부 헤더</th></tr><tr><td>내부 데이터</td></tr></table> |
   ```

2. **복잡한 다단계 구조**
   ```html
   <table>
     <tr>
       <th>모듈</th>
       <th>기간</th>
       <th>설명</th>
     </tr>
     <tr>
       <td>HTML/CSS</td>
       <td>2주</td>
       <td>웹 페이지 레이아웃 및 스타일링 기초</td>
     </tr>
     <tr>
       <td>JavaScript</td>
       <td>3주</td>
       <td>동적 콘텐츠 생성 및 DOM 조작</td>
     </tr>
   </table>
   ```

3. **긴 텍스트 데이터가 포함된 중첩 테이블**
   ```html
   <tr>
     <td>프론트엔드 프레임워크(React)</td>
     <td>3주</td>
     <td>컴포넌트 기반 UI 설계 및 상태 관리</td>
   </tr>
   ```

4. **다양한 데이터 유형이 혼재된 구조**
   - **모듈명**: 기술 스택과 도구명
   - **기간**: 숫자와 단위 조합
   - **설명**: 상세한 학습 내용과 목표

### 특히 문제가 되는 상황:
1. **교육 과정 안내서**
   - **대학교, 학원, 기업 교육** 등에서 **커리큘럼 상세 정보 제공**
   - **수강생과 교육 담당자**가 **모듈별 내용과 일정을 파악**해야 하는 필수 정보
   - **세부 커리큘럼 소실**로 **교육 과정 선택 및 계획 수립 불가**

2. **프로젝트 계획서 및 업무 매뉴얼**
   - **복잡한 프로젝트의 단계별 세부 작업**을 **체계적으로 정리**
   - **각 단계의 담당자, 기간, 산출물** 등을 **구조화하여 표현**
   - **세부 계획 정보 소실**로 **프로젝트 관리 및 업무 분담 기능 마비**

3. **제품 사양서 및 기술 문서**
   - **제품 기능, 사양, 호환성** 등의 **복합적 정보 정리**
   - **구매 결정**이나 **시스템 도입** 시 **상세 비교 검토 자료**
   - **핵심 사양 정보 소실**로 **의사결정 지원 기능 완전 상실**

4. **공공기관 정책 자료**
   - **정책 세부 내용, 시행 계획, 예산 배분** 등의 **복잡한 정보 구조**
   - **의회 보고, 시민 공개, 언론 브리핑** 등에서 **상세 데이터 제공**
   - **정책 세부 내용 부재**로 **투명성과 설명 책임 이행 불가**

### 예상되는 원인:
1. **마크다운-HTML 혼합 파싱 한계**
   - **마크다운 테이블 파서**와 **HTML 테이블 파서**가 **독립적으로 작동**
   - **중첩된 구조**에서 **HTML 부분을 마크다운 셀 내용으로 인식 못함**
   - **복합 구조 처리**를 위한 **고급 파싱 로직 부재**

2. **셀 내용 HTML 태그 처리 부재**
   - 마크다운 테이블의 **개별 셀 내용**에서 **HTML 태그를 무시**
   - **인라인 HTML**은 지원하지만 **블록 레벨 HTML 테이블은 무시**
   - **셀 단위 HTML 파싱 기능**의 **근본적 부재**

3. **HWPML 중첩 테이블 변환 한계**
   - 한글 문서의 **테이블 내 테이블** 구조 표현의 **기술적 제약**
   - **복잡한 중첩 구조**를 **한글 문서 형식으로 변환**하는 **매핑 로직 부재**
   - **대체 표현 방식** (예: 들여쓰기, 목록 등)으로의 **변환 기능 없음**

4. **테이블 구조 복잡도 처리 한계**
   - **단순한 2차원 테이블** 구조만 지원하고 **3차원적 중첩 구조 미지원**
   - **계층적 데이터 표현**에 대한 **변환 전략 부재**
   - **복잡한 데이터 구조**를 **평면적 테이블로 변환**하는 **알고리즘 없음**

### 심각도:
- 🐛 심각 (Critical)
- 🎨 시각적 오류
- **높은 심각도** - 복잡한 구조화 정보의 핵심 내용 소실
- **교육 과정, 프로젝트 계획, 제품 사양**의 **가장 중요한 세부 정보 완전 무시**
- **전문 문서의 실질적 가치 심각 훼손**
- **의사결정 지원 기능 마비**
- 모든 템플릿에서 동일한 문제로 **대체 방안 제한적**
- **복잡한 데이터 구조 문서 작성 기능 원천 제약**
- **업무 매뉴얼, 교육 자료의 완성도 심각 저하**

### 임시 해결 방안:
1. **평면적 테이블로 분리**
   - 중첩 테이블을 **별도의 독립적인 테이블**로 분리
   ```markdown
   ## 웹 개발 과정 상세 커리큘럼
   | 모듈 | 기간 | 설명 |
   |------|------|------|
   | HTML/CSS | 2주 | 웹 페이지 레이아웃 및 스타일링 기초 |
   ```
   - **구조적 연관성**은 약화되지만 **내용은 보존**

2. **목록과 테이블 조합**
   ```markdown
   ### 웹 개발 과정
   - **설명**: 웹 애플리케이션 개발의 기초
   - **커리큘럼**:
     - HTML/CSS (2주): 웹 페이지 레이아웃 및 스타일링 기초
     - JavaScript (3주): 동적 콘텐츠 생성 및 DOM 조작
   ```
   - **가독성은 좋지만** **표 형태의 체계적 정리 효과 상실**

3. **섹션별 분할**
   - 각 과정을 **개별 섹션**으로 분리하고 **내부에 테이블 배치**
   ```markdown
   ## 웹 개발 과정
   웹 애플리케이션 개발의 기초
   
   | 모듈 | 기간 | 설명 |
   |------|------|------|
   | HTML/CSS | 2주 | ... |
   ```
   - **내용은 완전히 보존**되지만 **비교 분석 용이성 감소**

4. **단순 텍스트 나열**
   ```markdown
   | 과정 | 커리큘럼 |
   |------|----------|
   | 웹 개발 | HTML/CSS(2주), JavaScript(3주), React(3주), Node.js(4주) |
   ```
   - **간단한 요약**은 가능하지만 **상세 정보 대폭 축약**

### 근본적 해결 방안 제안:
1. **중첩 HTML 테이블 완전 지원**
   - **마크다운 테이블 셀 내 HTML 테이블**을 **정확히 파싱**하는 고급 기능
   - **복잡한 중첩 구조**도 **안정적으로 처리**하는 파서 개발
   - **HTML 표준 완전 준수**

2. **HWPML 복합 테이블 구조 매핑**
   - 한글 문서의 **셀 병합, 중첩 구조** 등을 활용한 **복잡한 테이블 표현**
   - **3차원적 데이터 구조**를 **2차원 테이블로 효과적 변환**
   - **시각적 구분**과 **논리적 계층** 유지

3. **계층적 데이터 전용 변환 모드**
   - **중첩 테이블이 포함된 문서**를 **자동 감지**
   - **교육 과정, 프로젝트 계획서** 등에 **특화된 변환 옵션**
   - **복잡한 구조**를 **가장 적합한 형태**로 **자동 최적화**

4. **하이브리드 구조 지원 강화**
   - **마크다운과 HTML의 장점**을 **모두 활용**하는 고급 파서
   - **복잡한 데이터 구조 표현력**과 **한글 문서 호환성** 동시 확보
