# 버그 리포트

## 어떤 버그인가요?

> 마크다운의 기본 서식(굵게(**), 기울임(*), 취소선(~~) 등)이 한글 문서로 변환 시 적용되지 않고 일반 텍스트로만 변환되는 현상이 발생합니다. 이는 모든 템플릿(6개)에서 동일하게 발생하는 문제입니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 서식 테스트
3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
# 동남아 여행 가이드

## 소개
동남아시아는 **아름다운 해변과 *이국적인 문화***로 여행객들의 마음을 사로잡습니다. 또한, 다양한 스트릿 푸드와 ~~높은 물가로 알려진~~ **친절한 현지인들**을 만날 수 있습니다.

## 주요 여행지
1. **태국 방콕**  
   - *왕궁*과 *사원* 방문  
   - **짜오프라야 강 보트 투어: *강변 야경 감상***  
   - ~~우기(6월~10월)~~ **방문 시 주의**
[이하 생략]
```

<br><br>

## 어떤 과정에서 버그가 발생하였나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - 원본: 굵게(**), 기울임(*), 취소선(~~) 등의 서식이 적용된 텍스트
   - 결과: 모든 서식이 무시되고 일반 텍스트로만 변환됨
   - 6개의 모든 템플릿에서 동일한 문제 발생

### 예상되는 원인:
1. 마크다운 파서가 서식 문법을 인식하지 못함
2. HWPML 변환 과정에서 서식 정보가 손실됨
3. 한글 문서 템플릿의 스타일 매핑이 되어있지 않음
4. 중첩된 서식(예: **텍스트 내 *기울임***) 처리 로직 부재
