# 버그 리포트

## 어떤 버그인가요?

> **오래된 시스템에서 이관된 데이터**나 **마크다운 문법 오류가 포함된 문서**에서 **오류가 그대로 출력**되어 **오류 복구 기능이 부족**한 버그입니다. **다양한 소스(Word, HTML, 텍스트 등)에서 변환 시 오류 혼입**, **사용자가 마크다운에 익숙하지 않아 발생하는 실수**, **여러 부서에서 작성한 문서 통합 시 서식 불일치** 등 **실무 환경에서 빈번히 발생**하는 상황에 대한 **오류 감지 및 자동 복구 기능**이 전무합니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. **실행 환경**: Windows 10, Python 가상환경  
2. **테스트 문서**: 오래된 시스템에서 이관된 데이터 검토 요청 (서식 오류 포함)  
3. **테스트한 템플릿**:  
   - template_ex_01.hml ❌ 문법 오류 그대로 출력  
   - template_ex_02.hml ❌ 문법 오류 그대로 출력  
   - template_ex_03.hml ❌ 문법 오류 그대로 출력  
   - 새템플릿.hml ❌ 문법 오류 그대로 출력  
   - 템플릿문서.hml ❌ 문법 오류 그대로 출력  
   - 템플릿문서1.hml ❌ 문법 오류 그대로 출력  

<br><br>

## 실제로 뭐가 잘못되었나요?

### 🔍 **발견된 마크다운 문법 오류들**
1. **텍스트 서식 오류** ❌
   - `*사용자명: 김철수 (기울임꼴이 닫히지 않음...`
   - `**진행 중*` (굵게 시작, 기울임꼴로 끝남)
   - `**부서: 기획조정실` (굵게 태그 닫히지 않음)

2. **링크 및 이미지 오류** ❌
   - `[파일명](경로 (괄호가 안 닫힘)`
   - `[텍스트][누락된_참조_링크]` (참조 정의 없음)
   - `![로고이미지](logo.png (이미지 설명 닫히지 않음)`

3. **표(테이블) 구조 오류** ❌
   - 구분선 열 개수 부족: `|---|:---:|---`
   - 데이터 행의 열 개수 불일치

4. **코드 블록 오류** ❌
   - 펜스 코드 블록 닫는 태그 누락
   - 들여쓰기 코드 블록 중간에 들여쓰기 부족

5. **각주 오류** ❌
   - `[^미정의각주]` 참조 정의 없음
   - 각주 정의에서 들여쓰기 불일치

6. **HTML 태그 오류** ❌
   - `<잘못된태그>...</잘못된태그>` 비표준 태그

### 💥 **현재 처리 방식의 문제점**
- **오류 복구 없음**: 문법 오류를 감지하고 자동 수정하지 않음
- **그대로 출력**: 잘못된 마크다운 문법이 원문 그대로 표시
- **사용자 경험 저하**: 오류가 있는 문서의 가독성 크게 떨어짐
- **일관성 없는 렌더링**: 일부는 정상, 일부는 오류 상태로 혼재

<br><br>

## 원래는 어떻게 되어야 하나요?

### ✅ **기대되는 정상 동작**
1. **오류 감지 기능**: 마크다운 문법 오류 자동 감지 및 사전 경고
2. **자동 복구 기능**: 간단한 오류 자동 수정 (닫히지 않은 태그 등)
3. **표 구조 정규화**: 테이블 열 개수 자동 조정 및 형식 표준화
4. **사용자 선택 옵션**: 
   - 엄격 모드: 오류 시 변환 중단
   - 관대 모드: 최대한 복구 시도 후 변환
   - 보고 모드: 오류 목록 생성 후 변환

### 🎯 **실무 활용도 증대**
- **데이터 이관 시나리오**: 오래된 시스템에서 문서 이관 시 오류 자동 처리
- **품질 관리**: 문서 변환 결과의 일관성 향상 보장
- **사용자 친화성**: 마크다운 초보자도 안전한 문서 변환 가능

<br><br>

## 추가적으로 도움이 될 만한 정보가 있나요?

### 📄 **테스트 문서 오류 예시**
```markdown
# 오래된 시스템에서 이관된 데이터 검토 요청 (서식 오류 포함 가능성 있음)

## 1. 사용자 계정 정보 (일부 발췌)

-   사용자 ID: `admin_user` (정상)
-   *사용자명: 김철수 (기울임꼴이 닫히지 않음...
-   **부서: 기획조정실
    -   직위: 사무관 (이 목록은 정상이나, 위 사용자명 서식이 전체에 영향을 줄 수 있음)

## 2. 첨부 파일 목록 (링크 오류 가능성)

-   [2024년 최종 보고서.pdf](file:///C:/Users/오류경로/보고서.pdf (괄호가 안 닫힘)
-   [2025년 사업계획안.hwp][누락된_참조_링크]
-   ![로고이미지](logo.png (이미지 설명이 닫히지 않음)

## 3. 회의록 요약 (테이블 깨짐 가능성)

| 일시 | 장소 | 참석자 | 주요 내용 |
|---|:---:|--- (구분선 열 개수 부족)
| 2025-05-15 | 대회의실 | 각 부서장 | 상반기 실적 점검 | 추가 항목으로 열 초과 |
```

### 🔧 **실제 발생 상황**
1. **데이터 이관 시나리오**
   - 오래된 시스템에서 문서 이관 시 문법 오류 발생 가능
   - 다양한 소스(Word, HTML, 텍스트 등)에서 변환 시 오류 혼입
   - 사용자가 마크다운에 익숙하지 않아 발생하는 실수

2. **공공기관 업무 현실**
   - 여러 부서에서 작성한 문서 통합 시 서식 불일치
   - 외부 업체 제출 문서의 품질 관리 부족
   - 급하게 작성된 문서의 검토 부족

### 💡 **단계적 개선 방안**
1. **1단계**: 치명적 오류 감지 및 알림
2. **2단계**: 일반적 오류 자동 복구
3. **3단계**: 고급 문법 검사 및 최적화
