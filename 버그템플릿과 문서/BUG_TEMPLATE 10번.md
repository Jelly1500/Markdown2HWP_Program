# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에서 수평선(`---` 또는 `-` 여러 개)이 한글 문서로 변환될 때 완전히 무시되는 현상이 발생합니다. 문서의 구분과 가독성을 위해 중요한 서식 요소인 수평선이 전혀 반영되지 않아 문서의 구조가 훼손됩니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 삼국지 인물 리뷰
3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml
   - template_ex_03.hml
   - 새템플릿.hml
   - 템플릿문서.hml
   - 템플릿문서1.hml

테스트한 마크다운 텍스트:
```markdown
## 관우
"의리의 화신" 관우는 유비의 의형제로 알려져 있습니다.  
그의 용맹함과 충정은 후세에도 전해집니다.  

---  
**관우의 주요 특징**  
- 「형주 수호」: 오나라의 손권이 쳐들어올 때, 형주를 끝까지 지킨 충성심  
- 「청룡언월도」: 긴 자루에 휜 날이 달린 무기를 휘두르는 모습이 유명  
- 「도원결의」: 유비, 장비와 함께 의형제를 맺은 상징적인 장면  

"도원결의 이후, 관우는 형주를 호위하며 유비를 도와 촉나라 기틀을 다졌다."  
---  

[다른 인물 설명...]

### 종합 평
삼국지 인물들은 각기 다른 배경과 목표를 가졌지만,  
서로 충돌하고 협력하며 난세를 헤쳐 나갔습니다.  

----  
"관우와 장비의 의리는 촉의 기틀을 다졌고,  
조조의 냉철함은 위나라를 건국했으며,  
제갈량의 지략은 촉나라에 마지막 희망을 불어넣었고,  
손권의 정치 수완은 오나라를 안정시켰다."  
----  
```

<br><br>

## 어떤 과정에서 버그가 발생했나요?

1. 위 마크다운 텍스트를 파일로 저장
2. 각각의 템플릿으로 변환 테스트 수행
3. 변환 결과 확인:
   - 모든 템플릿에서 동일한 문제 발생:
     * 수평선(`---`, `----` 등)이 완전히 무시됨
     * 수평선 위아래 문단이 구분 없이 연결됨
     * 문서의 구조적 가독성이 크게 저하됨
   - 공무원 문서 작성 시 자주 사용되는 구분선 기능 부재

### 예상되는 원인:
1. 마크다운 파서가 수평선 문법을 인식하지 못하는 문제
2. HWPML 변환 시 수평선에 대응하는 한글 문서 요소 매핑 누락
3. 템플릿에 수평선 스타일 정의가 없음
4. 한글 문서의 구분선 기능과 마크다운 수평선 간의 연결 로직 부재
