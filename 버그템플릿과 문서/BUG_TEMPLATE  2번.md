# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에서 표 안에 다른 표가 중첩되어 있을 경우, HWP 변환 시 표 구조가 깨지거나 비정상적으로 출력되는 현상이 발생합니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10, Python 가상환경
2. 테스트를 수행한 마크다운 문서: 홈카페 레시피 (바닐라 라떼) 문서
테스트 문서 내용:
```markdown
# 홈카페 레시피: 바닐라 라떼

| 단계 | 설명 |
| :--: | :--- |
| 1 |
| 재료 | 양 |
| ---------- | ------- |
| 에스프레소 | 30ml |
| 우유 | 200ml |
| 2 | 에스프레소 추출 후 스팀 밀크와 섞기 |
| 3 | 바닐라 시럽(15ml) 추가 및 서빙 |
```

<br><br>

3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml  
   - template_ex_03.hml
   - 템플릿문서1.hml(사하구청)



## 어떤 과정에서 버그가 발생하였나요?

1. 위의 마크다운 문서를 작성하여 저장
2. MD2HWP 프로그램 실행
3. 변환 버튼 클릭
4. 결과 확인 시 hwp 문서에서 중첩 표가 정상적으로 표시되지 않음 
   - 표 안의 표 구조가 유지되지 않음
   - 셀 병합이 제대로 이루어지지 않음
   - 내부 표의 구분선이 사라지거나 왜곡됨
