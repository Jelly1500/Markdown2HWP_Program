# 버그 리포트

## 어떤 버그인가요?
> markdown 문법 중 각주 [^1]로 된 문법이 변환되지 않음. [^1]은 삭제되어 변환되고 글 또한 삭제되어 변환됨

<br><br>

## 어떤 상황에서 겪으셨나요?
1. 실행 환경: 
   - OS: Windows 11
   - Python: 3.12

2. 테스트를 수행한 마크다운 문서:
```
## 서론

스마트 도시(Smart City)는 ICT 기술을 활용하여 도시 운영의 효율성과 시민 삶의 질을 향상시키는 것을 목표로 한다. 현재 국내 주요 도시들도 교통, 에너지, 환경 등의 분야에서 스마트 기술 도입을 확대하고 있으나, 지속가능성과 실효성을 확보하기 위한 전략적 접근이 필요한 시점이다[^1].

[^1]: 국토교통부, 『스마트시티 종합계획(2024)』
```

## 어떤 과정에서 버그가 발생하였나요?
> 마크다운 문법에 각주가 포함되면 해당 줄은 변환되지 않음 또한 각주 문법을 지원하지 않음.
