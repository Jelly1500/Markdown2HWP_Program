# 버그 리포트

## 어떤 버그인가요?
> 이모티콘 중 일부는 제대로 변환이 되지만 일부는 네모로 깨져서 나오는 것들이 있음. 

<br><br>

## 어떤 상황에서 겪으셨나요?
1. 실행 환경: 
   - OS: Windows 11
   - Python: 3.12

2. 테스트를 수행한 마크다운 문서:
```
💡 📈 🌳 🛠️ 와 같은 이모티콘이 변환되지 않았고 ⚡☀ 같은 이모티콘은 비슷한 이모티콘으로 변환이 되었음.
```
   

3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml  
   - template_ex_03.hml
   - template_ex_04.hml

<br><br>

## 어떤 과정에서 버그가 발생하였나요?
> 문서에 이모티콘이 포함되는 경우 변환시 네모로 깨져서 나오는 경우가 있음.
