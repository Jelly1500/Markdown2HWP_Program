# 버그 리포트

## 어떤 버그인가요?
>  https://github.com/Jelly1500/Markdown2HWP_Program/commit/6437aa52bf3b593a4730995a6d8035f5a3c4b745 링크 참고
> & 가 포함되면 &기호가 hwpml에서는 &amp;로 작성 됨 기존에는 & => &amp; 로 변환되도록 수정 완료 했으나 테이블 내부에 &가 포함된 경우
> 동일한 문제가 발생함.
<br><br> 

## 어떤 상황에서 겪으셨나요?
1. 실행 환경: 
   - OS: Windows 11
   - Python: 3.12

2. 테스트를 수행한 마크다운 문서: test20
```
| 구분         | 꿀팁 & 안내                                                                                                                                                                                                                                                                          |
|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **교통** | 대중교통 이용 (지하철 2호선 해운대역 하차). 축제 기간 중 주변 도로 통제 및 주차 공간 부족 예상.                                                                                                                                                                                                                                                                                               |
| **복장** | 가벼운 옷차림, 모자, 선글라스 필수. 밤에는 해변 바람이 쌀쌀할 수 있으니 가벼운 겉옷 준비.                                                                                                                                                                                   |
| **개인 위생**| 개인용 손 소독제 지참, 땀을 자주 닦고 충분히 수분 섭취.                                                                                                                                                                                                                    |
| **편의 시설**| **탈의실/샤워장**: 해수욕장 내 공공 시설 이용 가능 (유료). **의무실**: 해변 중앙에 위치, 응급 상황 시 도움 요청. **미아 보호소**: 해운대 관광안내소 옆 운영. **물품 보관함**: 해운대 해변 인근에 다수 위치.                                    |
| **안전 수칙**| 해변에서 수영 시 안전선 준수, 음주 후 입수 금지. 아이들과 동반 시 미아 방지 팔찌 착용.                                                                                                                                                                                  |
```

## 어떤 과정에서 버그가 발생하였나요?
> 테이블 내부에 &가 포함된 경우 변환이 되지 않고 알수 없는 오류가 발생했다고 나옴.
