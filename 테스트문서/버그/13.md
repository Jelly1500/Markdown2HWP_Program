# 버그 리포트

## 어떤 버그인가요?
> 중첩 md문법이 제대로 적용되지 않는 문제가 있음. ***스마트팜(Smart Farms)*** 의 경우 기울임과 강조가 같이 적용되어야 하는데 기울임 문법만 제대로 적용됨.

<br><br>

## 어떤 상황에서 겪으셨나요?
1. 실행 환경: 
   - OS: Windows 11
   - Python: 3.12

2. 테스트를 수행한 마크다운 문서: test35
```
 특히 **수직 농장(Vertical Farms)**과 ***스마트팜(Smart Farms)*** 기술은 최소한의 공간에서 최대한의 효율을 내는 혁신적인 방법론을 제시합니다.
```
   

3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml  
   - template_ex_03.hml
   - template_ex_04.hml

<br><br>

## 어떤 과정에서 버그가 발생하였나요?
>  ***스마트팜(Smart Farms)*** 을 변환했을 때 결과는 기울임 + 강조가 되어야 하는데 기울임과 적용되어서 변환이 됨.
