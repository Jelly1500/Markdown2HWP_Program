# 버그 리포트

## 어떤 버그인가요?
> markdown 문법 중 체크박스 리스트가 포함되는 경우 어색하게 변환되는 문제가 있음. 체크박스 변환이 별도로 구현되어 있지 않음.

<br><br>

## 어떤 상황에서 겪으셨나요?
1. 실행 환경: 
   - OS: Windows 11
   - Python: 3.12

2. 테스트를 수행한 마크다운 문서:
```
## 3. 체크리스트: 구현 단계

아래는 프로젝트 구현을 위해 검토해야 할 주요 항목들입니다.

* [ ] 프로젝트 팀 구성 완료
* [x] 초기 아이디어 회의 진행 (2025년 5월 20일)
* [ ] 관련 기술 자료 조사 및 분석
* [ ] 예산 확보 방안 논의
* [ ] 이해관계자 (시민, 정부, 기업) 의견 수렴
* [ ] 프로토타입 개발 계획 수립
* [ ] 법률 및 규제 검토
* [ ] 최종 제안서 완성 및 제출

```
   

3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml  
   - template_ex_03.hml
   - template_ex_04.hml

<br><br>

## 어떤 과정에서 버그가 발생하였나요?
> 마크다운 문법 체크박스 리스트 변환 시 어색하게 변환됨. 해당 문법을 변환하는 코드를 구현할 필요가 있어보임.
