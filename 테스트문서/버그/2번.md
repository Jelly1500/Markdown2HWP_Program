# 버그 리포트

## 어떤 버그인가요?
> markdown 문법 중 > 으로 시작되는 인용문의 경우 제대로 변환이 되지 않음. 글이 변환되지 않고 삭제되어 나옴.

<br><br>

## 어떤 상황에서 겪으셨나요?
1. 실행 환경: 
   - OS: Windows 11
   - Python: 3.12

2. 테스트를 수행한 마크다운 문서:
```
> "가족관계증명서 하나 떼는데 세 개의 사이트를 들락거려야 했어요."  
> — 시민 A씨, 2025년 설문 응답 중

```
   

3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml  
   - template_ex_03.hml
   - template_ex_04.hml

<br><br>

## 어떤 과정에서 버그가 발생하였나요?
> 마크다운 문법에 인용문이 포함되면 내부의 글이 변환시 삭제 됨.
