# 버그 리포트

## 어떤 버그인가요?
> " * 1. " 과 같은 문법의 경우 리스트 바로 뒤에 로마숫자로 변환되게 되는데 다음과 같이 변환 됨
> * 1. 
> 현재 프로그램에서는 순서 없는 리스트로 변환되고 다음줄에 순서 리스트로 변환이 됨. 

<br><br>

## 어떤 상황에서 겪으셨나요?
1. 실행 환경: 
   - OS: Windows 11
   - Python: 3.12

2. 테스트를 수행한 마크다운 문서: test20
```
* 1. 스마트폰이 없으면 불안하거나 초조함을 느낀다.
* 2. 식사 중에도 스마트폰을 보지 않으면 허전하다.
* 3. 잠자리에 들기 전이나 일어나자마자 스마트폰을 확인한다.
* 4. 스마트폰 사용 시간을 줄여야겠다고 생각하지만 잘 되지 않는다.
* 5. 스마트폰 때문에 학업이나 업무에 집중하기 어렵다.
* 6. 스마트폰 사용으로 인해 가족이나 친구와의 대화가 줄었다.
* 7. 걷거나 이동 중에도 스마트폰을 계속 사용한다.
* 8. 스마트폰이 없으면 세상과 단절된 느낌이 든다.
```
   

3. 사용했던 템플릿: 
   - template_ex_01.hml
   - template_ex_02.hml  
   - template_ex_03.hml
   - template_ex_04.hml

<br><br>

## 어떤 과정에서 버그가 발생하였나요?
> " * 1. " 문법의 경우 변환이 구현되어 있지 않아 부자연스럽게 변환되는 문제가 발생함.
