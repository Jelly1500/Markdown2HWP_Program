# 버그 리포트

## 어떤 버그인가요?

> `## 1.`, `## 2.`, `## 3.` 형식으로 번호를 포함한 헤딩을 작성했을 때,  
> 변환된 HWP 문서에서는 로마 숫자(예: Ⅰ, Ⅱ, Ⅲ)와 함께 **수동 번호까지 중복 출력됨**  
> 결과적으로 `"Ⅰ 1. 개요"`처럼 번호가 두 번 붙고, 시각적 혼란을 야기함

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 테스트 마크다운 문서:  
   - `ex16.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 마크다운에서 `## 1. 개요`처럼 수동 번호가 포함된 헤딩을 작성했음  
> - HWP 변환기에서 자동 스타일 적용 시 **로마 숫자 자동 번호 + 수동 번호**가 함께 출력됨  
> - 사용자가 붙인 번호를 제거하지 않으면 **이중 번호가 출력되어 문서 가독성 저하**
