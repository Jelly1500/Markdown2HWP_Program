# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서 내 `\` 문자와 숫자 조합이 포함된 **파일 경로 텍스트에서 숫자가 잘리는 현상**이 발생함.  
> 결과적으로 경로가 손상되어 원문 의미 전달이 불가능해짐

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전) 
2. 테스트한 마크다운 문서:  
   - `ex15.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 마크다운 문서에서 다음과 같은 경로를 작성함:  
>   `"Z:\시설점검사진\2025"`  
>
> - 그러나 변환된 HWP 결과물에서는  
>   `"Z:\시설점검사진\202"` 또는 `"Z:\시설점검사진\20"`처럼  
>   뒤의 숫자가 일부 잘려 출력됨  
>
> - 이로 인해 실제 파일 경로가 훼손되며, 사용자가 경로 복사 또는 참조에 혼란을 겪을 수 있음
