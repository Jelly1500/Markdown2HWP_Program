# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서 내 **제목-하위제목-리스트로 구성된 계층 구조가 변환 시 무너지는 문제**  
> 특히 `**2. 제목**` → `### 하위제목` → `- 리스트` 순으로 정의된 구조가  
> HWP 변환 결과에서는 `###` 항목이 오히려 상위처럼 출력되고 `**2.` 항목은 하위로 밀려 계층이 반대로 표현됨

---

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: `ex94.md` (중소형 체육시설 전력 소비 효율 개선 방안 초안)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

---

## 어떤 과정에서 버그가 발생하였나요?

다음과 같이 계층을 가진 마크다운 구조:

```markdown
**2. 시설 유형별 주요 특징**

### 체육관형 시설 (대형 환기 설비 포함)

- 중앙집중식 제어 시스템 도입 필요  
  - 연동형 제습장치 도입 시 약 14% 절감 가능  
  - 기존 전등의 LED 전환율은 78% 수준

### 커뮤니티센터형 소규모 시설

- 피크타임 자동 차단 스케줄링 권장  
  - 비가동 시간대(22:00~05:00)에도 냉난방 가동 기록 존재  
- 개별 냉난방기별 사용량 측정 불가  
  → 계량기 분리 예산 소요: 약 6,200천 원/시설
```

→ 실제 출력 결과에서는 체육관형 시설, 커뮤니티센터형 소규모 시설이 더 강조되어
**2. 시설 유형별 주요 특징**이 리스트 제목처럼 축소되어 출력됨

###로 지정한 항목이 **로 지정한 상위 항목보다 더 두껍고 강조되어 보임

결국 상위 → 하위 → 리스트 흐름이
→ 하위(더 강조됨) → 상위(약하게 표현됨) → 리스트 순서처럼 역전됨
