# 버그 리포트

## 어떤 버그인가요?

자동 번호가 이미 기호 또는 제안 번호가 포함된 제목에서도 **강제로 추가**되어  
**번호 중복 현상**이 발생합니다.

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: ex66.md (시민참여 정책 제안 결과 보고)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

- 마크다운 내 `### [제안 0077] "1인가구 생필품 지원"` 형태로 작성  
- 변환된 문서에서 자동 숫자 `2.`가 앞에 붙어  
  `2. [제안 0077] "1인가구 생필품 지원"` 으로 출력됨  
- **사용자가 기호 또는 식별번호를 명시한 경우 자동 번호는 생략되어야 함**
