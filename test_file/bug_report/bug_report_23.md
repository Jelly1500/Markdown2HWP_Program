# 버그 리포트

## 어떤 버그인가요?

문서 내 `**굵은 글씨**` 마크다운 강조 문법이 **일부 항목 텍스트에서 적용되지 않고 일반 텍스트로 출력**됩니다.

예:  
`1. **고장 자전거 회수 지연**` → 실제 출력: `1. 고장 자전거 회수 지연` (굵게 처리 누락)

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: ex54.md (2025년 공공자전거 운영 현황 및 개선 검토)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

- 번호 매기기(`1.`, `2.` 등)와 함께 작성된 `**강조 텍스트**`가 변환 시 일반 텍스트로 처리됨  
- 특히 `1. **텍스트**` 구조에서 `**` 마크다운 문법이 **무시**됨  
- 동일 문서 내 다른 위치의 강조는 정상 처리되었으므로,  
  **넘버링과 함께 사용 시 강조 구문 누락** 가능성 있음
