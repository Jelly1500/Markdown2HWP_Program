# 버그 리포트

## 어떤 버그인가요?

> `### 3.1`, `### 3.2` 형식의 하위 헤딩에서  
> 자동 스타일 번호(`1`, `2`, ...)와 수동 번호(`3.1`, `3.2`)가 **동시에 출력되어 중복 번호 문제**가 발생함

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 테스트 문서:  
   - `ex24.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 마크다운 문서에서 `### 3.1. 예약 지연 및 로딩 문제` 등 수동 번호를 포함한 하위 제목을 사용  
> - HWP 변환 시 자동 스타일에 의해 `1`, `2` 등 번호가 자동 삽입되며  
> - 결과적으로 `"1 3.1 예약 지연 문제"`처럼 **이중 번호**가 출력됨
