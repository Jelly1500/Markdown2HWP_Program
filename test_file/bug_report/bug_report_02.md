# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에 `#` 헤더가 두 번 이상 등장할 경우,  
> 첫 번째 제목 외의 다른 `#` 헤더들도 모두 **같은 '문서 제목 스타일'**로 변환됨  
> 이에 따라 문서 중간에 **불필요한 대제목이 반복 출력**되는 문제가 발생함

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 테스트를 수행한 마크다운 문서:  
   - `ex06.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> 마크다운 문서 상단에는 `# 문서 제목`이,  
> 하단에는 `# 후속 조치 및 개선안`이라는 또 다른 H1 헤더가 있었음.  
> 변환 결과 두 문단 모두 HWP 상의 "문서 제목 스타일"로 출력되어  
> **문서 중간에 본문 내용과 어울리지 않는 큰 제목이 중복 등장**함.  
> 실제 목적은 소단락 구분이었으나, 시각적 충돌을 유발하며 문서 완성도를 떨어뜨림.
