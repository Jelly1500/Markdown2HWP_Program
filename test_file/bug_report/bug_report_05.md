# 버그 리포트

## 어떤 버그인가요?

> `ex09.md` 변환 시 다음과 같은 **문서 구조 관련 오류**가 발생함:
>
> 1. `>` 인용문이 변환된 HWP 결과에서 **완전히 누락됨**
> 2. `####` 제목과 그 하위 `- 리스트` 간의 계층 구조가 무너져,  
>    제목이 일반 문단처럼 출력되고 하위 항목과 구분되지 않음

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전) 
2. 테스트를 수행한 마크다운 문서:  
   - `ex09.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> 마크다운 인용문(`>`)이 변환된 문서에 전혀 나타나지 않았으며,  
> 제목-내용 계층 구조를 표현한 `#### 제목` 아래 `- 리스트`들도  
> 제목과 같은 수준으로 들여쓰기되거나 스타일이 분리되지 않아  
> 문서 전체의 시각적 위계가 무너지고, 독자가 항목 구조를 파악하기 어려웠음
