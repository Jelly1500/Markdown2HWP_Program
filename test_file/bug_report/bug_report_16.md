# 버그 리포트

## 어떤 버그인가요?

> 마크다운의 두 개의 번호 목록 그룹이 `---`로 분리되어 있음에도  
> 변환 결과에서는 두 그룹이 별개의 목록으로 처리되지 않고,  
> 번호만 다시 `1. 2. 3.`으로 출력되어 시각적 혼란을 유발함.

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 테스트 문서: ex29.md  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

- 마크다운 목록의 두 블록이 번호가 동일한 (1. 2. 3.) 형식을 가지며  
  `---`로 구분되어 있었음
- 변환 결과에서는 그룹의 단락 구분 없이  
  두 개의 1. 2. 3. 목록이 **동일한 스타일**로 이어짐  
- 결과적으로 시각적으로 **중복된 번호 목록**처럼 보이며  
  병렬 구조인지, 하위 구조인지 해석이 어려움
