# 버그 리포트

## 어떤 버그인가요?

`▣` 기호를 포함한 제목이 변환 시 자동 번호가 추가되어  
**"Ⅴ.▣ 예산 개요"**처럼 **이중 기호가 출력되는 문제**가 있습니다.

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: ex65.md (2025년 도심 정비 추진 계획 요약 자료)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

- 마크다운 문서 내 `## ▣ 예산 개요` 와 같은 항목을 작성  
- 변환된 HWP 문서에서는 **자동 번호(Ⅴ.) + 사용자 기호(▣)** 가 중복되어  
  `Ⅴ.▣ 예산 개요`로 출력됨  
- `▣`는 사용자가 넣은 텍스트 강조용 기호이므로 **자동 번호와 중복 출력되면 안 됨**
