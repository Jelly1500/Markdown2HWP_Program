# 버그 리포트

## 어떤 버그인가요?

`ex07.md` 문서의 변환 과정에서 다음과 같은 문제가 **복합적으로 발생**함:

1. **제목이 너무 길 경우 글자가 겹치거나 잘리는 현상**
2. **인용문(`>`) + 굵은 글씨(`**`) + 특수문자(`※`) 조합이 포함된 문장이 아예 출력되지 않음**
3. **수동 번호(`1.`, `2.`, `3.`)가 자동 리스트처럼 처리되어 순서가 꼬임**

---

## 어떤 상황에서 겪으셨나요?

- 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
- **테스트를 수행한 마크다운 문서**: `ex07.md`  
- 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

---

## 어떤 과정에서 버그가 발생하였나요?

`ex07.md`를 변환기에 붙여넣고, `template_ex_01.hml`을 적용하여 HWP로 변환한 결과  
다음과 같은 문제가 **동시에 발생**함:

- `# 2025년 1분기 업무추진비 집행 내역 및 적정성 검토 보고`  
  → 한 줄로 출력되며 **오른쪽 본문 텍스트와 겹침 현상 발생**

- `> **※ 간식비는 식음료 지출로 구분되어 문제 없음.**`  
  → 문장이 변환된 결과물에서 **완전히 누락됨**

- 본문 내 수동 번호(`1.`, `2.`, `3.`)가  
  → 자동 리스트처럼 처리되어 `1.`, `2.`, `1.`처럼 **번호가 꼬이는 현상** 발생

---

## 기대 동작

- **길이가 긴 제목**은 줄바꿈 처리 또는 자동 폰트 축소로 **텍스트 겹침 없이 출력**되어야 함
- `> **※ 문장` 형태의 인용문은 **빠짐없이 그대로 렌더링**되어야 함
- 수동 번호 리스트는 **자동 번호 리스트와 구분**되어 **사용자 지정 순서 유지**가 필요함
