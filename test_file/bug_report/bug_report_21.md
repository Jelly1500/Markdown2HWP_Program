# 버그 리포트

## 어떤 버그인가요?

인용형 번역 예시 문단에서 `"→ ❌"` 기호 앞에서 개행이 누락되어,  
번역 전 문장과 번역 결과가 한 줄에 이어서 출력되는 문제가 발생합니다.  
**시각적 구분이 되지 않아 오해 소지가 있음**.

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: ex49.md (영문 서비스 안내 및 다국어 민원 응답 지원 방안 보고)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

- `"1. 문장"` 뒤에 이어지는 `"→ ❌ 번역문"`이 **개행 없이** 같은 줄에 표시됨  
- Markdown 원문에서는 줄바꿈이 명확히 존재하지만,  
  변환 결과에서는 한 줄로 병합되어 가독성 저하됨
