# 버그 리포트

## 어떤 버그인가요?

> `ex17.md` 변환 시 `bad escape \p` 오류로 인해 문서가 아예 변환되지 않음

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 사용 문서: `ex17.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 마크다운 문서 내에 다음과 같은 경로 문자열이 포함되어 있음:
>   `\\network_drive\reports\2025\parking_summary.md`  
>
> - 해당 경로 문자열이 변환 과정 중 정규표현식 처리될 때  
>   `\p`가 잘못된 이스케이프 문자로 인식되며 파서 오류 발생
>
> - 그 결과 **문서 전체가 변환되지 않고 중단됨**
