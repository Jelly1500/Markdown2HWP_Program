# 버그 리포트

## 어떤 버그인가요?

기호(`1.`, `●`, `※`)를 포함한 문단에서 **개행이 누락되고 줄바꿈 없이 출력**되는 문제가 발생합니다.  
특히 `1.` 이후 문장이 개행되지 않고, `●`, `※` 항목과 같은 줄에 이어서 출력됩니다.

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: ex48.md (2025 상반기 지역민원 응답 사례 요약 보고)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

- `1.` 뒤 문장이 개행되지 않고 `●` 문단과 같은 줄에 출력됨  
- `●`, `※`도 각각의 줄로 분리되어야 하나 개행 없이 이어짐  
- **줄 나눔 처리 누락으로 시각적 구분이 무너짐**
