# 버그 리포트

## 어떤 버그인가요?

넘버링 하위 리스트(예: `3.1`, `3.2`)가 개행 없이 같은 줄에 출력되는 문제가 발생합니다.  
리스트 항목이 계층 구조로 구분되어야 함에도 불구하고 **한 줄로 병합되어 가독성이 저하**됩니다.

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: ex62.md (교육지원 강화 요청에 대한 협조 여부 회신)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

- `3.` 항목의 하위 리스트 `3.1`, `3.2`가 각각 줄바꿈되지 않고  
  상위 항목 또는 서로와 **같은 줄에 이어서 출력**됨
- 마크다운 상의 계층 리스트 구조(`1.`, `1.1`, `1.2`)가  
  변환 과정에서 **개행 처리되지 않고 병합됨**
