# 버그 리포트

## 어떤 버그인가요?

> 마크다운에서 작성한 `**굵게 강조**` 구문이 변환된 HWP 문서에서 일반 텍스트로 출력됨.  
> 예를 들어 `**기술 중심 제안**`이라는 강조 구문이 반영되지 않고 단순 텍스트로 나타남.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. **테스트를 수행한 마크다운 문서**: `ex39.md`  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

<br><br>

## 어떤 과정에서 버그가 발생하였나요?

> 마크다운 문서에서는 `**기술 중심 제안**`과 같이 `**` 문법으로 강조된 텍스트가 존재하였음.  
> 변환 결과 HWP에서는 해당 텍스트가 **강조되지 않은 일반 본문**으로 처리되어 시각적인 구분이 사라졌음.
