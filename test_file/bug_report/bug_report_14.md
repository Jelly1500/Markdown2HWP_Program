# 버그 리포트

## 어떤 버그인가요?

> 인용문(`>`) 블록 내부에서 줄바꿈이 존재할 경우,  
> 변환된 문서에서는 개행이 무시되고 **본문처럼 한 줄로 붙어서 출력**됨

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 테스트 문서: `ex27.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 마크다운에서 `>`로 시작하는 인용문을 여러 줄로 작성했음  
> - 하지만 변환기 또는 템플릿 적용 시, **줄바꿈 없이 한 문장으로 이어붙음**  
> - 결과적으로 시각적으로 **인용문인지 아닌지도 불분명한 상태**로 출력됨
