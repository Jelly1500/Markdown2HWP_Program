# 버그 리포트 

## 어떤 버그인가요?

`ex08.md` 변환 시 다음과 같은 문제가 발생함:

1. 마크다운 **표의 마지막 줄에 `|` 문자가 하나 부족하면**,  
   해당 행이 표로 처리되지 않고 일반 문단처럼 출력됨

2. **인용문(`>`) 문장이 변환 결과에서 아예 출력되지 않음**

3. **이탤릭 문장(`_※ ...`)이 별도 문단임에도 불구하고**,  
   줄바꿈 없이 앞 문단과 이어져 출력됨

---

## 어떤 상황에서 겪으셨나요?

- 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
- **테스트를 수행한 마크다운 문서**: `ex08.md`  
- 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

---

## 어떤 과정에서 버그가 발생하였나요?

- 표의 마지막 행에 `|` 기호가 부족하여,  
  해당 줄이 표로 처리되지 않고 **일반 문단처럼 출력**되었음

- `> "회계 담당자의 이직으로 인해..."`  
  → **인용문이 변환된 문서에서 아예 누락됨**

- `_※ 현장 확인 결과 실제 청소는 이루어졌으나..._`  
  → **이탤릭 문장은 마크다운 상 개행되었지만**,  
     HWP 결과에서는 **줄바꿈 없이 앞 문단과 연결되어 출력됨**
