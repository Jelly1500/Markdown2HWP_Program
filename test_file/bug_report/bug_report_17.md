# 버그 리포트

## 어떤 버그인가요?

> 마크다운 문서에 포함된 emoji 문자 (예: ✅, ⚠️ 등)가 HWP로 변환 시 깨지거나 공백으로 출력됩니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. **테스트를 수행한 마크다운 문서**: `ex31.md`
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

<br><br>

## 어떤 과정에서 버그가 발생하였나요?

> 마크다운 문서에서 상태표시용으로 ✅, ⚠️ 등의 emoji를 사용한 후 변환기를 통해 `.hwp`로 출력하였으나,  
> 해당 이모지들이 변환된 문서에서는 □(깨진 문자) 또는 공백으로 처리되었습니다.  
> 본문뿐 아니라 표 내부, 리스트, 인용문 등 위치에 관계없이 일관되게 발생함을 확인했습니다.
