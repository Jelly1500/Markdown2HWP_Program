# 버그 리포트

## 어떤 버그인가요?

마크다운 내 표(`| 부처 | 총 보유 데이터 | 개방 데이터 | 비고 |`)가  
HWP 변환 시 **표 형식이 아닌 일반 문단 형태로 출력**됨.  
셀 구분이나 테두리가 적용되지 않아 **표로 인식되지 않고**,  
데이터 정렬이 어긋나 **가독성이 저하**됨.

---

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. **테스트를 수행한 마크다운 문서**: `ex04.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

---

## 어떤 과정에서 버그가 발생하였나요?

- 마크다운 문서에서 `|---|---|---|` 형식을 포함한 표 내용을 복사하여  
  변환기에 붙여넣은 뒤 `template_ex_01.hml` 템플릿을 선택하고 변환을 수행함
- 변환된 HWP 파일에서는 해당 표가 **표가 아닌 본문 문단**처럼 처리됨
- 각 행이 **문단 단위로 줄바꿈되어** 출력되고, 열 간 구분이 사라져  
  **원래의 행-열 구조가 완전히 붕괴됨**
