# 버그 리포트

## 어떤 버그인가요?

표 삽입 후 이어지는 **번호 리스트 항목이 `1.`부터 다시 시작되는 문제**가 발생합니다.  
정상적으로는 `1. 2. 3. (표) 4. 5.`처럼 이어져야 하나, 변환 결과에서는  
`1. 2. 3. (표) 1. 2.`처럼 **리스트 번호가 잘못 초기화**됩니다.

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: ex50.md (2025년 하반기 행정자료 관리 시스템 개선 의견 회신)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

- 마크다운 번호 리스트 `1. 2. 3.` 작성 후 표 삽입  
- 이후 이어지는 항목 `4.` `5.`가 **자동으로 다시 `1.` `2.`로 출력됨**  
- 표가 리스트 구조를 중단시킨 것으로 인식되는 것으로 보임
