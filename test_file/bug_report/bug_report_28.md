# 버그 리포트

## 어떤 버그인가요?

마크다운 원문에서 **단락 간 시각적 구분을 위해 의도적으로 한 줄 개행(`\n\n`)한 부분이,  
HWP 변환 시 모두 무시되고 단순 개행 처리**되어 **가독성이 심각히 저하**됩니다.  

특히 안내문이나 정책 요약 자료처럼 단락 간 의미 구분이 중요한 문서에서  
**문단 구분이 사라져 전체가 한 덩어리처럼 보이는 문제**가 발생합니다.

---

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: `ex76.md` (2025년 폭염대응 정책 요약 안내문)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

---

## 어떤 과정에서 버그가 발생하였나요?

- 마크다운 원문에는 **단락 구분을 위한 공백 줄**(`\n\n`)이 삽입되어 있었음  
- 그러나 변환된 HWP 문서에서는 **해당 줄바꿈이 무시되고, 줄간 간격 없이 바로 이어짐**  
- 그 결과 **문단별 내용이 구분되지 않고, 하나의 덩어리처럼 압축된 형태로 출력**

---

## 기대 동작

- 마크다운 내 2줄 개행(공백 줄)은 HWP 변환 시 다음과 같이 처리되어야 함:
  - **문단 간 간격을 두고 출력** (상하 마진 또는 스타일 간격)
  - 또는 **명시적인 빈 줄 출력** (예: `줄바꿈 + 줄바꿈` = 가시적 문단 구분)
