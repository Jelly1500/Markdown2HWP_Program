# 버그 리포트

## 어떤 버그인가요?

문서 내 `---` 마크다운 구분자가 변환 시 **시각적 문단 구분 없이 일반 개행처럼 출력**됩니다.  
공식 회신문 등에서 단락 구분이 명확히 필요함에도 **시각적 분리가 거의 없어 가독성이 떨어지는 문제**가 발생합니다.

---

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서: `ex69.md` (복합 민원 병합 회신)  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

---

## 어떤 과정에서 버그가 발생하였나요?

- 마크다운 원문에 `---`을 사용하여 의미상 단락을 명확히 구분함  
- 그러나 변환 결과물에서는 해당 구분이 단순한 줄바꿈 1회로만 처리되어  
  시각적으로 하나의 덩어리처럼 연결되어 출력됨  
- **단락 구분 없이 이어붙인 것처럼 보여**, 사용자 입장에서 구간별 정보 구별이 어려움

---

## 기대 동작

- `---`는 변환 시 아래 중 하나로 반영되어야 함:
  - **실선 스타일 구분선** 삽입 (HWP 스타일 상의 가로줄)  
  - **상하 여백 1줄 추가 + 흐린 라인 또는 점선 삽입**  
  - 또는 **명확한 단락 구분**이 가능한 스타일 적용 (ex. 단락 간 패딩, 색상 구분 등)
