# 버그 리포트

## 어떤 버그인가요?

> `ex11.md` 문서의 변환 결과에서 다음과 같은 문제가 확인됨:
>
> 1. 마크다운 표에서 셀 구분 기호 `|` 개수가 불일치하면, 해당 행이 표로 인식되지 않고 일반 문단처럼 출력됨  
> 2. `**굵은 제목**` 다음 줄에 오는 `_이탤릭 문장_`이 줄바꿈 없이 이어져 출력됨  
> 3. `> 인용문 + 리스트` 조합이 있는 문단은 변환 결과에서 **완전히 누락**됨

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전) 
2. 테스트를 수행한 마크다운 문서:  
   - `ex11.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 표 구조에서 `|`가 부족한 행이 있었는데, 이 행들이 표로 처리되지 않아 문서 시각 구조가 깨졌음  
> - 강조 문법과 줄바꿈이 함께 있는 경우, 줄바꿈이 무시되고 한 문단으로 이어져 가독성이 저하됨  
> - 인용문(`>`)이 포함된 리스트 문단은 변환 결과에서 완전히 누락되어 정보가 유실됨
