# 버그 리포트

## 어떤 버그인가요?

> `$12.5\%$`, `$15.3\%$` 등의 수식 표현이 **수식으로 인식되지 않고**  
> 변환된 결과에서 `$` 기호 자체가 **그대로 출력됨**

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 테스트 문서:  
   - `ex26.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 마크다운 문서에서 수식 표현으로 `$...$` 구문을 사용하였고  
>   내부에 `\%` 등 LaTeX 특수기호 포함
>
> - 하지만 변환기에서 `$...$`를 **수식으로 해석하지 않고 일반 텍스트로 처리**함  
> - 결과적으로 `%`는 텍스트로 나오지만 `$` 기호까지 함께 출력되는 문제가 발생
