# 버그 리포트

## 어떤 버그인가요?

> `ex45.md` 문서의 **"4. 개선 권고 사항"** 항목에서,  
> 리스트 항목 내 `→` 기호 앞에서 개행이 발생해야 하지만  
> 실제 변환 결과에서는 개행되지 않고 한 줄로 이어졌습니다.

<br><br>

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 테스트를 수행한 마크다운 문서: `ex45.md`  
3. 사용 템플릿:`template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

<br><br>

## 어떤 과정에서 버그가 발생하였나요?

> 마크다운 문서 작성 시, 리스트 항목 내부에 줄바꿈이 존재하도록 작성하였으나  
> 변환 결과에서는 줄바꿈이 무시되고 **화살표 기호를 포함한 문장이 이어져 출력**되었습니다.  
> 이로 인해 문단이 **불규칙하게 합쳐지거나 가독성이 떨어지는 결과물**이 출력되었습니다.
