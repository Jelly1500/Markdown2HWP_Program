# 버그 리포트

## 어떤 버그인가요?

> `ex12.md` 문서의 변환 결과에서 다음과 같은 리스트 관련 오류가 발생함:
>
> 1. `- -` 형태로 중첩된 리스트는 인식되지 않고 일반 문장처럼 출력됨  
> 2. `- 1.`, `- 2.` 구조로 작성된 넘버링 리스트가 모두 `1.`로 출력되어 순서가 유지되지 않음  
> 3. `①`, `②`, `③` 등의 목록이 줄바꿈 없이 한 문장처럼 이어져 출력됨

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)  
2. 테스트를 수행한 마크다운 문서:  
   - `ex12.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 중첩 리스트를 `- -` 형식으로 작성했으나, 변환 결과에서는 병합된 일반 문장처럼 출력되어 의미 전달이 어려워졌음  
> - 리스트 번호가 `1.`, `2.`, `3.`이 아닌 `1.`, `1.`, `1.`로 출력되어 순서 인식이 깨졌음  
> - 요청사항 항목에서 `①`, `②`, `③`이 개행되지 않고 한 문장으로 붙어 출력되어 가독성이 저하됨
