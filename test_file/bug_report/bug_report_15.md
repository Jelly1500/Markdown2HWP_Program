# 버그 리포트

## 어떤 버그인가요?

> 리스트(`-`)로 구성된 항목 사이에 `|` 기호가 포함되어 있을 경우  
> 변환 시 **줄바꿈이 무시되고 항목이 이어서 출력**됨

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 10 / 마크다운 → HWP 변환기 (내부 실행 버전)
2. 테스트 문서: ex28.md  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> - 실제 마크다운은 리스트 항목으로 구성되어 있었고  
>   항목 구분용으로 시각적 구분자인 `|` 문자가 사용됨  
> - 하지만 변환 시 `|` 기호가 테이블 구문으로 잘못 인식되어  
>   리스트 줄바꿈이 무시됨

## 예시

```markdown
- A 항목 내용  
- B 항목 내용  
| - 조치1  
- 조치2  
| C 항목 제목  
- 내용...
