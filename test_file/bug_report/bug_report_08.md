# 버그 리포트

## 어떤 버그인가요?

> `ex13.md` 문서의 변환 결과에서 다음과 같은 중요한 정보 유실 문제가 발생함:
>
> 1. `>` 인용문 문장이 HWP 결과물에서 전혀 출력되지 않음  
> 2. 마크다운 표(`|` 사용)가 제대로 렌더링되지 않아, 열 구분이 사라지고 구조가 깨짐  
> 3. 코드 블록(````plaintext```)으로 작성된 구조 예시가 HWP에서 **완전히 누락**

## 어떤 상황에서 겪으셨나요?

1. 실행 환경: Windows 11 / Python 3.10 / PySide6 6.7  
2. 테스트를 수행한 마크다운 문서:  
   - `ex13.md` ,`ex14.md`  
3. 사용했던 템플릿: `template_ex_01.hml`, `template_ex_02.hml`, `template_ex_03.hml`, `template_ex_04.hml`

## 어떤 과정에서 버그가 발생하였나요?

> `ex13.md`,`ex14.md`를 변환기에 입력한 뒤 변환하였을 때 다음과 같은 문제가 관찰됨:
>
> - 인용문(`>`)으로 작성된 사용자 피드백이 누락되어 문서의 응답자 의견 섹션이 빈약해졌음  
> - 제안 접수 현황 표가 마크다운 표로 작성되어 있었으나,  
>   출력 결과에서는 표 형식이 유지되지 않아 데이터 구분이 어려워졌음  
> - 사이트 구조 예시를 표현한 코드 블록이 변환 결과에서 완전히 사라짐
