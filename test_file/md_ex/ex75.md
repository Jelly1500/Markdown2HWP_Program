# 2025년 6월 2주차 정책조정회의 요약 및 후속 조치 정리

○○과에서는 6월 12일 개최된 실무정책조정회의 결과를 아래와 같이 정리합니다.

---

## 1. 회의 개요

- 일시: 2025.06.12.(목) 10:00 ~ 11:30  
- 장소: 시청 본관 중회의실  
- 참석: 기획예산과, 정보화지원과, 환경정책과 등 8개 부서  

---

## 2. 주요 논의사항

- 중장기 도시녹지 확보 방안(2026~2030) 추진 방향 정리  
- 공공앱 통합 서비스 설계안 사전 검토  
- 폭염 대비 무더위쉼터 운영방식 개선안 공유  
- 예산 통합조정 권한 확대 관련 실무 적용범위 검토

---

## 3. 실행 항목 도출

1. 도시녹지 확보안은 도시디자인과-공원녹지과 간 매칭 계획 수립 필요  
2. 공공앱 설계안은 6월 말까지 1차 개발범위 확정 후 시범 테스트 추진  
3. 무더위쉼터 운영시간 연장 검토는 복지정책과 소관으로 이첩  
4. 예산 통합조정안은 기획예산과에서 추가 검토 후 차기 회의 안건 상정 예정

---

## 4. 후속 조치 체크리스트

- [ ] 공공앱 1차 개발범위 확정안 작성 (정보화지원과)  
- [ ] 무더위쉼터 운영지침 수정초안 제출 (복지정책과)  
- [ ] 도시녹지 우선 확보기준안 수립 (공원녹지과)  
- [ ] 예산통합조정 관련 추가자료 제출 (기획예산과)

---

해당 항목은 6월 24일 정책조정실 중간 점검 시 재보고 예정입니다.
