# ○○축제 사전 준비사항 협조 요청

## 2. 부서별 협조 요청 사항

행정지원팀에는 주요 인력 배치 및 통신 장비 확보를,  
도시정비과에는 행사장 주변 환경 정비 및 안전 바리케이드 설치를 요청드립니다.

문화관광과는 부대 행사 일정 조율 및 홍보물 제작을 담당해주시기 바랍니다.

### 체크리스트: 사전 조치 필요 항목

- [ ] 행사장 주변 수목 정비 일정 확인
- [ ] 9월 10일까지 차량 통제 안내문 배포
- [ ] 축제 당일 비상연락망 최신화
- [ ] 무대 설치 시 전기 인입 여부 사전 확인
