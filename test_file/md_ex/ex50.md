# 2025년 하반기 행정자료 관리 시스템 개선 의견 회신

## 1. 회신 개요

귀 부서에서 제출한 “행정자료 시스템 개선 요청”에 대해  
다음과 같이 회신 드립니다.

본 문서는 2025년 6월 현재 시스템 사용 현황 및  
자료 입력·조회 기능 중심으로 작성되었으며,  
향후 정기 개편과 연계하여 적용 가능성을 검토하고자 합니다.

---

## 2. 개선 제안 요약

### 주요 개선 항목:

1. 자료 입력 항목 정렬 순서 변경 요청  
2. 화면 내 **단위 행정항목 구분 라벨 추가 요청**
3. 다음 표는 최근 3개월 기준 내부 오류 발생 구간입니다:

| 오류 구간 | 원인 항목 | 비고 |
|------------|-----------|------|
| `자료등록 > 신규문서` | 항목 누락 시 강제 종료 발생  
- 사용자는 ‘확인’ 버튼을 누르지 않은 채도 진행 가능함 | UI 확인 필요 |
| `조회 > 다중조건 검색` | 조건 3개 이상 입력 시 검색 결과 미표시  
  - 필터 초기화 후에도 잔존 필터값 유지됨 | 처리 완료 예정 |

4. 자료 보관 연한 자동 알림 기능 도입 검토 요청  
5. 문서 유효기간 만료 항목 자동 필터링 기능 제안

---

### 2.1 항목별 세부 설명

#### A. 입력 항목 구조 정비

- 현재 시스템에서는 [문서번호 → 분류코드 → 기관명] 순으로  
입력 항목이 구성되어 있으나,  
**실무자 의견에 따라 기관명을 최우선으로 배치할 필요가 제기됨**

#### B. 문서 열람 필터 기능

- ‘최근 열람 순’, ‘부서 기준’, ‘작성자 기준’ 등  
중복 필터 옵션 선택 시 오류 빈도 높음

---

## 3. 향후 조치 계획

- 2025년 8월까지 일부 항목 시범 반영 예정  
- 부서별 1차 교육 후 **현장 피드백 수렴 기간** 운영  
- 개선안 최종 적용 시기는 2025년 10월 예정
