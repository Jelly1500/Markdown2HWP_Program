# 주요 정책 제안사항 검토 결과표

각 부서에서 접수한 2025년도 정책 제안 중 주요 안건에 대해  
사전 검토 결과를 아래와 같이 정리합니다.

---

## 1. 제안별 사전 검토 내역

| 제안명 | 내용 요약 | 검토 의견 |
|--------|-----------|-------------|
| 공원 내 안내표지 개선 | 기존 표지판이 시야 확보에 불리함. → 저시인성, 통일되지 않은 디자인, 기둥 훼손 등 복합 문제 있음 | 시인성 높은 디자인(아이콘 중심), 동일 위치에 크기 통일한 표지로 교체 필요 - 예산 소규모 소요(300만원 내외) |
| 쓰레기 분리배출 이력제 도입 | 가정 내 분리배출 기록 관리 시스템 도입 요청 : RFID 기반 인식 방식 등 고려 가능성 있음 | - 개인정보 이슈 : RFID 태깅 시 거부감 발생 가능<br>- 실효성 검증 선행 필요(타지자체 유사사례 없음) |
| 마을버스 실시간 위치 공유 앱 도입 | 시민 불편 해소 목적, 노선별 대기시간 안내 앱 개발 제안<br>특정 노선에만 우선 도입 요청 | - 타 앱과의 기능 중복 여부 검토 필요<br>- 실증노선(○○구 03번)으로 1개월 우선 테스트 검토 중 |

---

## 2. 정리

상기 제안사항은 부서별 실무자 검토를 거쳐  
적용 가능성, 예산 소요, 제도적 제약 등 주요 요소를 기준으로 판단한 초안입니다.

→ 최종 반영 여부는 실무부서별 판단 및 정책심의위원회 결정에 따라 추후 확정될 예정입니다.
