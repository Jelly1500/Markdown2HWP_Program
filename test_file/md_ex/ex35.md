> **본 보고서는 자동분류 시스템 운영 실적을 기반으로 작성되었으며, 특정 민원 유형 분류 실패 사례를 중심으로 점검을 수행하였습니다.**

## 1. 시스템 개요

- 명칭: 스마트민원 자동분류 시스템  
- 도입 시기: 2024년 10월  
- 목적: 온라인 민원 접수 시 민원 유형 자동 판별 및 분류  
- 적용 채널: 홈페이지, 모바일앱, 무인민원기 등

---

## 2. 주요 기능 흐름

```
입력된 민원 텍스트 →
유사 민원 사례 DB 대조 →
분류 확률 계산 →
기준치 이상 항목 자동 분류 →
최종 담당부서 매핑
```

> ※ 예시 민원문: “건물 외벽 파손되어 위험해 보입니다”  
> → 분류 결과: [시설안전] → **도시관리과**로 자동 이관

---

## 3. 오류 사례 점검

> “자동분류된 민원이 잘못된 부서로 배정되어 처리 지연이 발생했습니다.”  
> – 시민 응답, 2025.03.17

### 3.1. 사례 A

- 입력 민원: “신호등이 고장났습니다.”  
- 자동 분류: _시설과_ → 담당 부서: **교통행정과** (오류)

>> “교통 신호기 관련 민원은 교통행정과 담당입니다.”  
>> – 부서 내부 지침, 2023.09 제정

### 3.2. 사례 B

- 입력 민원: “야간에 길이 너무 어두워 위험합니다.”  
- 자동 분류: **방범과** → 실제 담당: _도로시설과_

---

## 4. 개선 제안

- 주요 키워드 리스트 지속 갱신
