# 2025 공공시설 내 시민 편의 개선 의견 보고

## 1. 개요

시민 제안 및 민원 데이터를 기반으로  
공공청사, 도서관, 체육시설 등에서의 **불편 사항**을 분석하였으며,  
시설 유형별 주요 개선 요청 항목을 다음과 같이 정리함.

---

## 2. 주요 시민 요구사항

1. 냉난방 온도 조절권 제공 요청  
2. 의자 및 테이블 수량 부족 문제  
3. 여성 화장실 대기 시간 감소 방안  
4. 아동 놀이공간 접근성 개선  
5. 휴게공간 내 와이파이 불안정 이슈

---

## 3. 시설 유형별 분석

### 3.1 공공청사

- 민원 대기 공간 협소  
* 무인 발급기 설명 부족  
+ 대기 순번 호출 음성 미출력 문제 발생

    일부 공간은 천장이 낮아 체감 소음이 큼  
  민원인의 이동 동선과 휴게 공간 간 동선이 교차함

---

### 3.2 도서관

* 콘센트 부족  
+ 전등 밝기 조절 불가 (특히 열람실 내부)  

    도서관 내 냉방 강도 조절 민원이 매월 15건 이상 발생  
  소규모 열람공간에서 통신장비 사용 제한 요구도 있었음

---

### 3.3 체육시설

- 탈의실 사물함 수량 부족  
- 샤워 공간 물 온도 불안정

    낮 시간대 혼잡도가 높아 대기 시간이 20분을 초과하는 경우가 있음  
  일부 지역은 배수관 교체 지연으로 악취 민원 지속 발생

---

## 4. 개선 요청 우선순위 기준

+ 응답 비율 15% 이상  
- 기술적 난이도 ‘보통’ 이하  
* 예산 소요가 연간 5천만 원 이하

→ 위 조건 충족 시, 즉시 적용 검토 대상임

---

## 5. 향후 계획

- 시민 이용 공간 구조 재배치 설계 용역 추진 예정  
- 다중 리스트 형태의 의견 수렴 형식 개발 검토  
- 2025년 9월까지 시설별 소규모 개선안을 시범 도입할 예정
