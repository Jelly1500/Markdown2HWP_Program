# 2025년 공공 API 활용 정책 현황 보고

## 1. 개요

○○시는 공공데이터 개방 확대 정책의 일환으로  
2024년부터 주요 API 서비스를 외부에 공개해오고 있음.  
본 보고서는 현재까지의 API 활용 현황 및 피드백을 종합한 중간 결과 보고임.

---

## 2. 개방된 주요 API 목록

- 공공버스 노선 API
- 실시간 공공와이파이 위치 API
- 생활폐기물 수거 일정 API

---

## 3. 활용 예시 (개발자 의견 인용)

> “공공 API 문서화는 대체로 잘 되어 있으나, 샘플 응답이 포함되지 않아 연동 시 확인이 어렵습니다.”

예시 응답은 다음과 같음:

```
{
  "stationName": "시청역",
  "arrivalTime": "3분 후 도착",
  "route": "155번"
}
```

---

## 4. 활용 현황 요약

| 항목 | 수치 | 비고 |
|------|------|------|
| API 호출 수 | 28,453건 | 2025년 1~5월 기준  
| 등록 개발자 수 | 344명 | 인증 기준 등록  
| 민원 건수 | 17건 | 대부분 문서화 관련 문의

---

## 5. 민원 유형별 요약

1. 문서에 응답 예시 없음
2. 인증키 만료 시 오류 메시지 불명확
3. 속성 설명 부족 (예: `arrivalTime`, `route`)

---
