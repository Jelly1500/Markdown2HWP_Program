# 2025 디지털 민원 응답 품질 개선 방안 보고

## 1. 배경

최근 1년간 디지털 민원 접수량은 **약 32.8% 증가**하였으며,  
특히 **모바일 채널을 통한 접수 비중이 61.2%**로 전체의 과반 이상을 차지함.

이에 따라 민원 응답의 정확성·신속성뿐 아니라,  
디지털 플랫폼 상에서의 **가독성과 표현 일관성**이 중요하게 부각되고 있음.

---

## 2. 주요 문제 유형

### 2.1 응답문 내 용어 중복

> 응답 문서 중 "관련 기관"이라는 표현이 4번 이상 반복되는 사례가 전체의 21.7%

### 2.2 형식 불일치

> 접두어 사용 예시: “○ 관련 사항”, “- 추진 계획” 등이 혼재되어 일관성 결여  
> 특히, 표 형식이 아닌 단락형 숫자 나열 시 오류 다수 발생

예시:
```
1. 전년도 예산 집행률: 91.4%
2. 미이행 사유: 2건 (휴폐업 포함)
3. 금년 신규 항목: 총 4건 (환경부 2, 교육청 2)
```

---

## 3. 플랫폼별 편차

3.1 PC 기반 민원접수

- 첨부문서 2개 이상 제출 비율: 68.1%  
- 평균 응답 시간: 2.7일

3.2 모바일 민원접수

- 음성 입력 활용률 증가 (2024년 대비 +19.3%)  
- 하단 고정 텍스트의 누락률 높음

---

## 4. 개선 권고 사항

- 응답문에서 동일 단어 반복 시 **동의어 활용 가이드 도입**  
- 마크다운 또는 서식기반 응답 작성 시  
  → 리스트는 `-` 또는 `*` 중 하나로 통일  
  → 숫자 리스트는 `1.`부터 순차 적용

**가이드 작성 예시 (부분):**
```
- 항목 분리 시: 기호는 `-`만 사용
- 예산 내역 정리 시: 테이블 또는 번호 사용
- 강조는 `**굵게**`로만 표기, 색상 X
```

## 5. 향후 계획
