## 3. 응모 프로그램 운영 계획

### 3.1. 경품 응모 절차

1. 행사장 입장 시 QR코드 배부  
2. 축제 중 최소 3개 부스 방문 → 스탬프 획득  
3. 스탬프 완성 후 안내소 제출  
4. 경품 추첨 시간에 현장 응모함 추첨

#### 3.1.1. 유의사항

- 1인 1회 참여만 가능  
- 스탬프 미완성 시 자동 제외  
- **당첨자는 현장 발표 기준**
