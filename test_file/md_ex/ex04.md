# 공공데이터 개방 현황 및 활용 활성화 방안 보고

### 개요

공공데이터의 개방 확대 및 민간 활용 촉진을 위한 2025년 추진 현황을 보고드리며, 향후 대응 방향에 대하여 공유드립니다.









## 1. 개방 현황

- 총 개방 데이터셋 수: 1,280건
* 주요 분야
  - 교통정보
  - 환경자료
  - 복지 및 인구
- 부처별 개방률
    | 부처 | 총 보유 데이터 | 개방 데이터 | 비고 |
    |------|----------------|----------------|------|
    | 행정안전부 | 312 | 290 |
    | 환경부 | 201 | 190 | 이상 없음
    | 복지부 | 190 |    | 일부 누락

## 2. 주요 과제

1. *표준화 미비*  
데이터 구조가 기관별로 상이하여 이용자 혼란 발생
2. *메타데이터 부족*  
설명 필드가 빈 상태로 제공되는 경우 다수
3. *민간 수요 미반영*  
개방 대상 선정 시 수요자 의견 반영 미흡

## 3. 사례 소개

아래는 민간 활용 우수사례입니다:

    스타트업 A사는 공공 교통정보 데이터를 기반으로
    통합 실시간 버스 알림 서비스를 개발하여
    일 사용자 수 4만 명을 기록하였습니다.

## 4. 향후 계획

- 공공데이터 품질진단 주기적 시행(반기 1회)
- API 기반 실시간 개방 확대 (정적 파일 → 실시간 데이터 전환)
- 공공데이터 사용 후기 게시판 신설

> 민간 기업과 협업할 수 있는 플랫폼 구축이 필요하다는 의견이 다수 제기되었으며 이에 대한 실무 검토가 필요합니다

## 요청사항

각 부서는 4월 말까지 다음 사항을 제출 바랍니다:

1. 부서별 신규 개방 후보 목록(최소 5건 이상)
2. 개방 제한 사유가 있는 데이터에 대한 사유서
3. 민간 활용 제안 접수 사례(있는 경우)
