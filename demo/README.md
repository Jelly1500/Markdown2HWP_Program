변환을 지원하는 Markdown 문법을 정리하면 다음과 같습니다.

### ✅ 현재 지원되는 Markdown 문법:
- 제목 (`#`, `##`, `###`, `####`)
- 일반 단락 (`문장`)
- 리스트 (`-`, `*`, `1.`, `2.`)
- 링크 (`[텍스트](URL)`)
- 굵게 (`**텍스트**`, `__텍스트__`)
- 기울임 (`*텍스트*`, `_텍스트_`)

### 지원이 되지만 에러가 있는 Markdown 문법:
- 테이블 (`| 열 | 열 |`) 현재 테두리 없는 표로 생성되거나 마크다운 문법이 그대로 출력되는 현상 발생

- 인용문 (미지원)
- 체크리스트 (체크박스 없음)
